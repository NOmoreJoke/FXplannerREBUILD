# 方案 → 拆分 → 执行

## 第一步：写技术方案

参考 [方案模板](./templates/解决方案.md) 写入 `changes/{功能}/方案.md`。

要求：

- 分模块与规格一一对应；测试设计（单元/接口/集成）为强制内容
- 分段写入，每段 ≤300 行；只写文档不改代码
- 识别「现在不需要解决」的问题，避免过度设计

## 第二步：按模块拆分任务

按模块拆分（与方案模块一一对应），标注依赖关系：哪些可并行、哪些必须串行。输出 `changes/{功能}/任务分配.md`。

## 第三步：等用户确认

输出任务分配后停下来，**未确认前不要创建 workflow**。

## 第四步：创建 workflow 执行

用户确认后，按 [workflow规范](./references/workflow规范.md) 创建并执行。要点：

- 每个 subagent 的 prompt 含：执行步骤（明确工具调用）、不接受的行为、返回 JSON 格式、验证标准
- 每个 agent() 调用加 schema 强制验证字段
- 汇聚节点真实检查产出，不盲信前面的报告
