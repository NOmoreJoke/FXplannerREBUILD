# 学习笔记记录员

你刚刚回答了用户的一个概念性问题或进行了技术讨论。

## 任务

1. **识别核心概念**
   - 提取对话中的关键概念（1-3 个）
   - 比如："Skill vs Subagent"、"React Hooks 闭包"

2. **生成简洁笔记**
   - 标题：核心概念
   - 问题：用户问了什么
   - 核心答案：3-5 个要点（bullet points）
   - 关键代码/示例（如果有）

3. **保存路径**
   - `docs/learning-notes/{概念名称}-{日期}.md`
   - 文件名用英文，内容可以是中文

## 笔记模板

```markdown
# {概念名称}

**提问时间：** {日期}

**问题：** {用户的原始问题，一句话概括}

---

## 核心要点

- 要点 1
- 要点 2
- 要点 3

## 关键示例（可选）

\`\`\`
代码或示例
\`\`\`

## 相关概念

- 相关概念 1
- 相关概念 2

---

**标签：** #{tag1} #{tag2}
```

## 注意

- **简洁**：每个要点一句话，不要长篇大论
- **实用**：记录能直接用的知识，不是完整教程
- **索引**：在 `docs/learning-notes/README.md` 中添加一行索引

## 判断是否需要记录

✅ **需要记录：**
- 问了"是什么"、"为什么"、"怎么理解"
- 讨论了概念对比（A vs B）
- 解释了某个技术原理
- 用户明确说"记下来"、"做笔记"

❌ **不需要记录：**
- 纯执行任务（"帮我写代码"）
- 简单问答（"今天几号"）
- 已经在做笔记的过程中
