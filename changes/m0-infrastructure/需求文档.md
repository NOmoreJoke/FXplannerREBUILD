# M0 基础设施 需求文档

> 档位：Mini（基础设施模块，无独立页面，业务面为「币种范围 + 精度规则 + 计算标准」）。
> 依据：`docs/MVP功能模块&业务逻辑&专业术语/` doc 02、05、13、14 与 `docs/开发计划/MVP开发计划.md` M0 条目。

## 一、背景与范围

M0 是所有后续模块的公共地基，用户不会直接看到任何页面，但此后每一笔金额、每一个汇率、每一份成本都受本模块约束。它的正确性直接决定「钱算得对不对」。

**本次交付**：

1. 币种范围与精度规则的唯一定义（15 币种，系统统一维护、统一下发，各端不再各自维护）。
2. 金额与汇率计算标准（十进制运算、只在最终结果舍入一次、舍入为 0 拦截）。
3. 15 个计算例子的测试断言清单（作为 M4–M8 各模块验收的统一依据）。

**本次不做**：汇率数据源接入（M2）、所有页面与向导（M1 起）、任何具体业务的入账（M1 起）。

## 三、业务规则

### 3.1 币种清单统一维护

- 币种清单（代码、中英文名、精度、顺序）由系统唯一维护；首次设置、买入、计划、报告等所有功能都从系统取同一份清单。
- 任何功能不得自行写死币种清单。后续增删币种只改一处，全局生效。

### 3.2 金额精度

- 用户首次填写的金额必须大于 0。
- 超出该币种允许的小数位时，提示用户修改，系统不擅自改小或改大。
- 单笔金额上限：小于 100,000,000,000（各币种自身单位）；超限提示修改，不截断保存。

### 3.3 汇率精度

- 汇率统一按「1 单位外币 ＝ X 本位币」表达与展示。
- 采用的汇率按来源报价四舍五入保留 **8 位小数**，显示与计算都用该值；原始报价与来源一并留痕。
- 汇率必须是大于 0 的有效数字。
- 勘误：`docs/开发计划/MVP开发计划.md` M0 条目写「汇率 4 位小数」，与原始需求 doc 02 / doc 05 的「8 位小数」矛盾，**以 8 位小数为准**，开发计划已同步修订。

### 3.4 计算标准

- 所有金额计算使用十进制运算，中间过程不舍入、不截断。
- 仅对最终结果按对应币种精度四舍五入一次。
- 正数被舍入为 0 时不得入账（如：折算后金额、成本为 0），必须拦截并提示。
- 初始成本 ＝ 已有外币金额 × 本次采用的汇率，按本位币精度舍入；入账后不随后续汇率变化。

将 `14_业务逻辑清单.md` 的 15 个例子整理为可直接转为测试用例的断言清单（见同目录《15个计算例子-测试用例清单.md》），作为 M4 买入、M5 计划、M7 使用、M8 更正各模块功能验收与自动化测试的统一断言依据。本模块只负责清单本身的产出与维护。

## 五、验收标准（Given-When-Then）

1. **假如** 任一需要选择币种的功能加载，**当** 用户打开币种选择，**那么** 可见的 15 个币种及其精度与第二节表格完全一致。
2. **假如** 用户选择了日元，**当** 输入金额 100.5 并提交，**那么** 系统提示「日元金额只能为整数」，不予保存。
3. **假如** 用户选择美元（2 位小数），**当** 输入 100.999，**那么** 系统提示修改小数位，不自动舍入保存。
4. **假如** 来源报价为 7.123456789123，**当** 系统采用该汇率，**那么** 展示与计算均使用四舍五入到 8 位小数的 7.12345679，且原始报价与来源被完整留痕。
5. **假如** 本金 0.01 本位币、汇率 0.5，**当** 系统折算得到的外币数量舍入后为 0，**那么** 提交被拦截并提示，不产生任何记录。
6. **假如** 本位币为人民币、已有 1,000 美元、汇率为 7.20，**当** 初始持仓确认入账，**那么** 初始成本记为 7,200.00；**当** 之后汇率变为 7.30，**那么** 该笔成本仍为 7,200.00 不变。
7. **假如** 一笔计算由多步乘除组成，**当** 系统给出最终金额，**那么** 中间步骤未发生任何舍入，最终结果与「全精度算完再舍入一次」的理论值一致。
8. **假如** 币种清单需要新增一个币种，**当** 只在系统维护处修改，**那么** 所有功能（首次设置、买入、计划、报告）无需各自改动即可看到新币种。

## 六、术语

| 术语 | 含义 |
| ------ | ------ |
| 本位币 | 用户首次设置选定的核算基准币种，用于统一计算成本，设置后不可更换 |
| 初始成本 | 首次录入已有外币时按当时汇率折算的本位币金额，仅作成本起点 |
| 最小单位 | 币种金额的最小刻度（0.01 或 1） |
| 入账 | 系统正式记录一笔金额，成为账户余额与成本的一部分 |
