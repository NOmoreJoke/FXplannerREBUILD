# 15 个计算例子 → 测试用例清单

> 用途：M4–M8 各模块接口测试与 E2E 的统一断言依据（M0 交付物）。
> 原始出处：`docs/MVP功能模块&业务逻辑&专业术语/14_业务逻辑清单.md` 第二节。
> 通用前置（适用于所有用例）：各例独立，无其他计划/记录/资金变化；买入和使用均发生在账本起点之后；金额默认 USD，港币成本另行注明；「修改后」均指用户确认且保存成功后，仅输入/预览/取消/失败不改数据。

## 断言公式（全用例共用）

| 公式 | 定义 |
| ------ | ------ |
| 还需使用金额 | max(目标金额 − 累计已使用金额, 0) |
| 资金缺口 | max(还需使用金额 − 计划剩余分配, 0) |
| 资金已备齐 | 还需使用金额 > 0 且 资金缺口 = 0 |
| 资金已使用完成 | 累计已使用金额 ≥ 目标金额 且 计划剩余分配 = 0（经用户确认后计划完成） |
| 账户不变式 | 账户余额 = Σ各计划剩余分配 + 未分配余额 |

## 例01 计划内使用 4,000，仍然备齐

- **前置**：计划目标 10,000，已分配 10,000，累计已使用 0，账户余额 10,000，未分配 0。
- **操作**：确认使用 4,000。
- **断言**：目标 10,000 不变；累计已使用 4,000；还需使用 6,000；计划剩余分配 6,000；账户余额 6,000；未分配 0；缺口 0；状态仍「资金已备齐」，计划不自动完成。

## 例02 使用 4,000 误录，实际 400

- **前置**：例 01 使用后状态（已用 4,000，剩余分配 6,000，余额 6,000，未分配 0）。
- **操作**：更正使用金额 4,000 → 400（原因必填，日期与计划不变）。
- **断言**：累计已使用 400；还需使用 9,600；计划剩余分配 6,000 **不变**；账户余额 9,600；未分配 3,600；缺口 3,600；状态 备齐→尚未备齐；保留原使用版本、原因、前后值与成本影响；无分配变动则无「恢复分配」记录。

## 例03 使用改大 4,000→5,000，原分配足够

- **前置**：同例 02 更正前；原分配 6,000 可覆盖增量。
- **操作**：使用 4,000 → 5,000，一次确认。
- **断言**：累计已使用 5,000；还需 5,000；计划剩余分配 5,000；账户余额 5,000；未分配 0；增量 1,000 全部来自原计划分配；不重复扣整笔 5,000；状态仍备齐；使用来源明细关联原分配与本次更正。

## 例04 原计划分配 0，使用增加 1,000

- **前置**：目标 10,000，已用 4,000，剩余分配 0，账户余额 6,000，未分配 6,000。
- **操作**：使用 4,000 → 5,000，一次确认。
- **断言**：确认文案明确「从未分配补充分配 1,000 并立即用于本次更正」；最终剩余分配 0；未分配 5,000；账户余额 5,000；还需 5,000；缺口 5,000；补分配与使用两步**整体生效**（无中间态落库）；两者记录标明同一次更正。

## 例05 增加 1,000，原分配仅 600

- **前置**：目标 10,000，已用 4,000，剩余分配 600，未分配 2,000，账户余额 2,600。
- **操作**：使用 +1,000，一次确认（系统内部分两步：补分配 400、扣原分配 600、扣补分配 400）。
- **断言**：最终剩余分配 0；未分配 1,600；账户余额 1,600；累计已使用 5,000；缺口 5,000；确认界面同时展示原分配 600 与补分配 400 两种来源；三步一起保存，共扣 1,000，不按汇总额重复扣；补分配操作时间为更正时间，原使用日期不倒改。

## 例06 目标 10,000→12,000

- **前置**：进行中计划，目标 10,000，已用 4,000，剩余分配 6,000，账户余额 8,000，未分配 2,000。
- **操作**：预览目标改 12,000 → 确认。
- **断言**：目标 12,000；已用 4,000 不变；还需 8,000；剩余分配 6,000 **不变**；未分配 2,000 **不变**（不自动占用）；缺口 2,000；状态 备齐→尚未备齐；保留原目标与修改历史。

## 例07 目标 10,000→8,000

- **前置**：同例 06 修改前（与例 06 独立）。
- **操作**：确认「目标改 8,000，同时释放超额分配 2,000」。
- **断言**：目标 8,000；还需 4,000；剩余分配 4,000；未分配 4,000；账户余额 8,000 不变；缺口 0；目标修改与释放**同次生效**，无超额中间态；退回分配不减账户总额、不改已有使用；保留原/新目标与退回记录（同一次修改）。

## 例08 已用 4,000，目标拟改 3,000

- **前置**：目标 10,000，已用 4,000，剩余分配 6,000，余额 8,000，未分配 2,000。
- **操作**：提交目标 3,000。
- **断言**：拦截，提示「新目标不能低于已使用的 4,000 USD」；所有数值保持原值；不因差额为 0 接受修改、不释放分配；不生成成功修改记录。

## 例09 剩余需求 10,000，已分配 6,000，又输入 5,000

- **前置**：目标 10,000，已用 0，剩余分配 6,000，账户余额 12,000，未分配 6,000。
- **操作**：新增分配输入 5,000（上限 = min(未分配 6,000, 还需 4,000) = 4,000）。
- **断言**：拦截，提示超出 1,000；不自动截成 4,000；剩余分配 6,000、未分配 6,000、余额 12,000 不变；改为 4,000 确认后：剩余分配 10,000、未分配 2,000、余额 12,000、备齐；编辑总额按「拟新剩余分配 ≤ 还需使用金额」直接比较。

## 例10 交易日期更正改变 FIFO 顺序

- **前置**：两笔买入各 1,000 USD（第一笔 9 月 1 日成本 7,800 HKD、第二笔 9 月 2 日成本 8,000 HKD，费用已明确且含在成本内），9 月 4 日计划内使用 1,200 USD。
- **操作**：第一笔买入日期 9/1 → 9/3，确认更正。
- **断言**：更正前使用成本 7,800 + 200×8 = 9,400 HKD，更正后 8,000 + 200×7.8 = 9,560 HKD（+160）；剩余成本 6,400 → 6,240（−160）；剩余数量 800 不变；剩余单位成本 8 → 7.8；已使用成本+剩余成本恒为 15,800 HKD；使用数量与日期不变；预览展示顺序变化与 ±160 差异；保留日期前后值与批次成本归属。

## 例11 更正引起当前或历史资金不足

- **子例 a**：入账 1,000 USD、已用 400、剩 600、无剩余有效计划分配 → 币种改 CAD：拦截（USD 预览余额 −400），原入账/使用不变。
- **子例 b**：9/1 买 1,000、9/2 用 400 → 买入日期改 9/3：拦截（9/2 时点缺 400），原日期、余额、分配不变。
- **子例 c**：9/3 买 1,000、9/4 用 400 → 使用日期改 9/2：拦截（9/2 时点缺 400），不变。
- **通用断言**：提示含对应日期、使用记录与缺口；不借未来资金、不自动补期初；币种更正影响有效分配时先到计划调整再做余额校验；校验按完整记录（含其他可用来源），不按单一买入日期一律阻止。

## 例12 手续费未知→20 HKD

- **前置**：买入 1,000 USD、本金 7,800 HKD、手续费未知、无分配/使用。
- **操作**：手续费补录 20 HKD，确认。
- **断言**：成本 7,800 → 7,820 HKD；单位成本 7.8 → 7.82 HKD/USD；外币数量 1,000 不变；日志/预览写「未知→20」，**禁止**写「0→20」；若仍有其他费用未知的交易，费用未完整说明继续保留。

## 例13 使用达标后确认计划完成

- **前置**：目标 10,000，累计已使用 10,000，剩余分配 0，账户余额 = 未分配 = 0。
- **断言 a（达标时）**：显示「资金已使用完成」，不再显示「资金已备齐」；计划仍为进行中，等待用户确认。
- **断言 b（用户确认完成）**：计划状态 → 已完成；不再次扣款；全部交易/分配/使用/更正历史保留。

## 例14 已完成计划提高目标并重新开启

- **前置**：已完成计划，目标 = 已用 = 10,000，剩余分配 0，余额 = 未分配 = 0；拟改目标 12,000。
- **操作**：一次确认「重新开启并修改目标」。
- **断言**：目标 12,000；已用 10,000；还需/缺口 2,000；剩余分配 0（不自动分配）；余额/未分配 0；状态 已完成 → 进行中；资金状态 已使用完成 → 尚未备齐；既有使用成本不变；保留原目标、使用、完成历史，新增重开与目标修改记录；取消/失败不改正式数据。

## 例15 使用金额更正，计划仍已完成

- **前置**：已完成计划，目标 = 已用 = 10,000，余额 = 未分配 = 剩余分配 = 0；其中一笔使用误录 4,000，实际 3,600。
- **操作**：该笔使用 4,000 → 3,600（原因必填，预览后确认）。
- **断言**：累计已使用 9,600；账户余额 400；未分配 400；剩余分配 0；计划**保持已完成**；差额 400 回增为账面纠错，非退款；不恢复分配、不调目标、不重开、不新增重开记录、差额不标待补、不触发提醒；重算受影响成本；保留原使用版本、原因、日志与完成历史。
