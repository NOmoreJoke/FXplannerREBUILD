# 首页真实数据 - 接口契约与分工边界

> 本文件是 6 个并行 subagent 的唯一契约来源。改契约必须先改本文件。
> 关联规格：`changes/home-dashboard/规格.md`

## 1. 背结论

- `GET /api/home/state` **已返回**：accounts（币种+余额）、plans（targetAmount/allocatedAmount/remainingAmount/latestPrepDate/status 等）、latestRateObservedAt、三个分流布尔。
- **唯一缺口**：CostLot 聚合数据（持仓总成本、各币种平均成本）→ 新增接口补齐。
- 前端仪表盘组件目前为纯 mock，需切换为 `use-home-state` hook 消费真实数据。

## 2. 后端契约：`GET /api/home/portfolio`（新增，JWT 保护）

响应 `{ success: true, data, message }` 包装（同现有风格），`data` 结构：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `baseCurrency` | `string \| null` | `UserSettings.baseCurrency`；用户无 settings 记录时为 `null` |
| `totalRemainingCost` | `string` | Σ各币种剩余持仓成本（本位币计价），`toFixed(4)`；无持仓为 `"0.0000"` |
| `byCurrency` | `Array<ByCurrency>` | 仅含 `remainingQty > 0` 的币种，按 `currencyCode` 升序；无持仓为空数组 |

`ByCurrency`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `currencyCode` | `string` | ISO 4217 |
| `remainingQty` | `string` | Σ `remainingQty`，`toFixed(4)` |
| `totalRemainingCost` | `string` | Σ(`remainingQty × unitCost`)，`toFixed(4)` |
| `avgUnitCost` | `string` | `totalRemainingCost ÷ remainingQty`，`toFixed(10)`（对齐 CostLot.unitCost 的 Decimal(20,10) 口径） |

**口径假设（必须写进代码注释）**：`CostLot.unitCost` 以用户当前 `baseCurrency` 计价（本位币/外币买入价）；本位币历史变更不做重算。

**实现要求**：

- 查询按 `userId` 过滤，禁止全表聚合后内存过滤用户。
- DTO 放 `services/chat/src/home/dto/home.dto.ts`，每个 `@ApiProperty` 显式标注 type（项目红线）。
- controller 挂在现有 `HomeController`（`home.controller.ts`），注册进 Swagger。
- **不改动** `GET /home/state` 的既有响应与断言。

## 3. 前端 hook 契约：`use-home-state` 扩展

`lib/hooks/use-home-state.ts` 在现有返回基础上新增 `dashboard: HomeDashboardData | null`（state 请求失败时为 null）：

```ts
export interface HomeDashboardData {
  accountCount: number;
  currencies: string[];            // 去重升序
  accountCards: Array<{
    currencyCode: string;
    balance: string;               // 透传 state.accounts.balance
    avgUnitCost: string | null;    // 来自 portfolio.byCurrency；无持仓记录 → null
  }>;
  totalRemainingCost: string | null;  // portfolio.totalRemainingCost；portfolio 请求失败 → null（卡片显示 "—"，不阻塞整页）
  baseCurrency: string | null;
  latestRateObservedAt: string | null;
  focusPlan: {
    id: string;
    name: string | null;
    targetCurrency: string;
    targetAmount: string;
    allocatedAmount: string;
    remainingAmount: string;
    progressPercent: number;        // allocatedAmount/targetAmount×100 四舍五入取整，钳位 0-100；targetAmount=0 → 0
    latestPrepDate: string;
    daysUntilPrepDeadline: number;  // latestPrepDate 与本地今天的天数差（ceil 日历天）；负数=已逾期
    isOverdue: boolean;             // daysUntilPrepDeadline < 0
  } | null;                         // status=ACTIVE 的计划中 latestPrepDate 最早者；无 ACTIVE → null
}
```

- `focusPlan` 从 `state.plans` 派生，不发额外请求。
- portfolio 请求与 state 请求并行发起，互不阻塞（portfolio 失败只降级对应卡片）。
- 临时类型 `HomePortfolioData` 定义在 `lib/api/home.ts`，注释 `// TODO(home-dashboard): generate:api 后替换为 schema.gen.ts 生成类型`。

## 4. 组件改造清单（`components/business/home/home-dashboard.tsx`）

| 现状（mock） | 改造后 |
| --- | --- |
| 顶栏通知铃铛 | **删除** |
| 顶栏「监控时间 08:30」（写死） | `latestRateObservedAt` 格式化显示；null → 不显示角标 |
| 「同步失败」横幅 | **删除** |
| 统计卡「外汇账户 3 个 / USD·CAD·JPY」 | `accountCount` + `currencies`；无账户不渲染此卡 |
| 统计卡「持仓总成本 HK$246,380」 | `totalRemainingCost` + `baseCurrency`；null → "—" |
| 统计卡「偏离安全评分 68%」 | **替换**为「最新汇率刷新」卡（值=`latestRateObservedAt`） |
| 统计卡「最晚安全日期 2026-08-12」 | `focusPlan.latestPrepDate` + `daysUntilPrepDeadline`（"X 天" / "已逾期 X 天"）；null → 不渲染此卡 |
| 账户卡片「待收利息」行 | **删除**；保留余额 + 新增平均成本（`avgUnitCost`，null → "—"） |
| 计划提醒横幅（写死进度/建议金额） | `focusPlan`：`progressPercent` + 倒计时（逾期态红色文案）+ 「查看计划」链接；null → 不渲染 |
| 快捷「录入买入」按钮 | 保留，跳 `/transactions/new` |
| 全部写死数字 | **一个都不许剩**；数字格式化遵循 money 展示规则（金额 4 位小数源数据，展示可 2 位，统一走现有工具函数） |

空态规则：`hasAccounts=false && hasPlans=false` 走现有空状态页（不改）。
