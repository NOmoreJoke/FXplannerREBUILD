# 首页与导航调整 需求规格说明书（SRS）

> 规格只写「用户/业务能得到什么」，用业务语言。
> 技术方案另出（本文档不含 API、数据库设计）。
> 2026 年讨论拍板，决策人与开发共同确认。

## 一、引言

### 1.1 编写目的与读者

本文档用于对齐两项变更的范围与验收标准：① 左侧导航菜单精简与排序；② 工作台首页从静态占位数据切换为真实数据库数据。读者：产品、前端/后端开发、测试。

### 1.2 项目背景

FXPlanner 工作台首页（登录后 `/home`）当前为静态 mock 页（`home-dashboard.tsx` 注释明确"所有数据均为硬编码占位"），侧边栏菜单包含多个无对应页面的死链接入口。本变更让首页展示真实数据，并清理菜单。

### 1.3 术语与缩写

| 术语 | 含义 |
| --- | --- |
| 空状态引导页 | 无任何外汇账户且无任何换汇计划时，首页展示的引导页（`home-empty-state.tsx`），即"先建立第一笔跨币种资金准备"页面 |
| 首次设置向导 | 原 M1 规划的新用户强制向导（年龄/条款/本位币），已按产品决策取消，本期不恢复 |
| 最晚备汇日 | 计划上"必须开始换汇的最后期限"（Plan.latestPrepDate），逾期则无法按期备齐资金 |
| 持仓总成本 | 用户全部外币持仓折算为本位币的买入成本合计 |
| 平均成本 | 某币种持仓的加权平均买入汇率（本位币/外币） |

## 二、总体描述

### 2.1 系统目标

登录用户打开首页即看到与自己账户/计划相关的真实数据（无任何写死数字）；侧边栏菜单只保留有明确归属的入口，顺序符合使用频率。

### 2.2 用户角色

| 角色 | 能做什么 |
| --- | --- |
| 登录用户 | 通过侧边栏菜单进入首页/换汇计划/外汇账户/我的报告/设置；首页查看自己的真实账户与计划摘要 |

### 2.3 边界（明确不做什么）

1. **不恢复首次设置向导**：空状态引导页兼任新用户引导，两者为同一页面（已拍板维持现状）。
2. **不做评分/监控**：原 mock 的"偏离安全评分"卡无数据源，本期以"最新汇率刷新时间"卡替换。
3. **不做利息**：账户卡片不展示"待收利息"（无利息模块）。
4. **不做同步失败提示与通知**：删除 mock 的"同步失败"横幅与通知铃铛。
5. **不做补资金推荐算法**：计划提醒横幅只展示进度与倒计时事实，不给"需补齐 XXX 金额"的建议。
6. **「我的报告」「设置」本期仅占位**：只建最小占位页避免 404，功能后续迭代。
7. **不改动账户/计划/交易既有功能逻辑**，本次只动导航与首页。

## 三、功能需求（按模块）

### 模块1：侧边栏导航

1. **能力简述**：登录后左侧边栏固定展示 5 个菜单项，按指定顺序排列。
2. **菜单清单与顺序**（自上而下）：

   | 序 | 菜单 | 路由 | 本期状态 |
   | --- | --- | --- | --- |
   | 1 | 首页 | `/home` | 正常 |
   | 2 | 换汇计划 | `/plans` | 正常 |
   | 3 | 外汇账户 | `/accounts` | 正常 |
   | 4 | 我的报告 | `/reports` | 占位页 |
   | 5 | 设置 | `/settings` | 占位页 |

3. **核心场景与验收路径**：

   > `登录 → 看到侧边栏恰好 5 项，顺序为 首页→换汇计划→外汇账户→我的报告→设置 → 预期：不出现「路径比较」「历史模拟」及任何其他入口`

   > `点击任意菜单项 → 预期：跳转到对应页面，均不出现 404`

4. **状态规则**：当前路由对应菜单高亮不变（首页精确匹配、其余前缀匹配，子页面跟随父级）；侧边栏底部"个人计划卡片"（现写死"倒计时 8 天"）随首页真实数据改造一并处理：能从真实数据得出则显示，不能则移除，不留写死数字。

### 模块2：我的报告 / 设置占位页

1. **能力简述**：两个最小占位页，页面标题 + "功能开发中"提示，无任何操作。
2. **核心场景与验收路径**：

   > `侧边栏 点「我的报告」→ 预期：进入 /reports，看到页面标题与"开发中"提示，无报错`

   > `侧边栏 点「设置」→ 预期：进入 /settings，看到页面标题与"开发中"提示，无报错`

### 模块3：首页分流（维持现状）

1. **能力简述**：首页按用户数据状态二分流，规则不变：
   - 无账户 且 无计划 → 空状态引导页；
   - 有账户 或 有计划 → 数据仪表盘（模块4）。
2. **边界**：空状态引导页内容本期不改；首次设置向导不恢复（见 2.3）。

### 模块4：首页数据仪表盘（真实数据）

1. **能力简述**：展示登录用户自己的真实账户与计划摘要，页面上不存在任何写死的业务数字。

2. **页面区块与数据来源**（全部来自本人数据）：

   | 区块 | 内容 | 数据事实 |
   | --- | --- | --- |
   | 顶栏 | 日期 + 「录入买入」快捷按钮 | 日期为当天；按钮跳录入页 |
   | 顶栏 | 汇率监控时间 | 最新一次汇率观测时间（无数据时该角标不显示） |
   | 统计卡1 | 外汇账户 | 账户个数 + 币种代码列表（无账户不出此卡） |
   | 统计卡2 | 持仓总成本 | 全部持仓按买入成本折算本位币合计（无持仓显示 0） |
   | 统计卡3 | 最新汇率刷新 | 汇率全表最新观测时间（替换原"安全评分"卡） |
   | 统计卡4 | 最晚备汇日 | ACTIVE 计划中最早的最晚备汇日 + 距今天数（无 ACTIVE 计划不出此卡） |
   | 我的外汇账户 | 每币种一卡 | 余额 + 平均成本（本位币/外币），点击进账户详情 |
   | 计划提醒横幅 | 最紧迫 ACTIVE 计划 | 分配进度（已用/已分配）+ 最晚备汇日倒计时 + 「查看计划」入口 |

3. **核心场景与验收路径**：

   > `用户有 2 个外币账户（USD、JPY）和 1 个 ACTIVE 计划 → 打开首页 → 预期：账户卡显示"2 个 / USD · JPY"（与本人账户一致）；持仓总成本、平均成本、备汇日与本人数据一致，页面上找不到任何与他人或样例相关的数字`

   > `用户只有账户、没有计划 → 打开首页 → 预期：显示账户区块；不显示"最晚备汇日"统计卡与计划提醒横幅`

   > `用户没有任何汇率数据 → 打开首页 → 预期：不显示"最新汇率刷新"时间角标/卡片，页面不报错`

   > `新注册用户（无账户无计划）→ 打开首页 → 预期：看到"先建立第一笔跨币种资金准备"空状态引导页，看不到仪表盘`

   > `最晚备汇日已过（倒计时为负）→ 打开首页 → 预期：计划横幅按逾期状态展示（天数带"已逾期"），不显示负数倒计时`

4. **权限与状态规则**：所有数字仅来自当前登录用户本人数据，换账号登录看不到他人数据；金额/汇率展示精度遵循现有金额规则（固定 4 位小数传输、按币种精度展示）。

## 四、非功能需求

### 4.1 性能

- 首页首次加载（含仪表盘数据）< 2s（本地开发环境）。

### 4.2 安全

- 仪表盘接口仅返回当前认证用户本人数据（复用现有 JWT 守卫，不新增匿名可访问数据）。

### 4.3 运行环境

- 与现有 chat-web 一致：现代桌面浏览器，最小宽度按现有工作台布局（侧边栏 240px + 主区）。
