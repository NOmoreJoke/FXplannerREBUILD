# 技术方案：首页真实数据与导航精简（home-dashboard）

> 结论先行：本次 **0 张新表**、**1 个新接口**（`GET /api/home/portfolio`，CostLot 剩余持仓 SQL 聚合）、
> 前端 **1 个 hook 扩展 + 1 个组件重写 + 菜单重排 + 2 个占位页**。
> 类型链路走既有 `generate:api`（后端 DTO → OpenAPI → openapi-typescript），前端零手写共享类型。
> 契约来源：`changes/home-dashboard/接口契约.md`；验收标准：`changes/home-dashboard/规格.md`。

## 1. 背景与目标

`/home` 仪表盘为纯 mock（写死持仓总成本、安全评分、倒计时），侧边栏含死链接。
目标：首页全部数字来自登录用户本人真实数据；菜单收敛为 5 项（删「路径比较」「历史模拟」）；
「我的报告」「设置」以最小占位页落位避免 404。

既有 `GET /api/home/state` 已覆盖账户/计划摘要与分流三布尔，唯一缺口是 **CostLot 聚合**
（持仓总成本、各币种平均成本）→ 新增 portfolio 接口补齐，与 state 并行消费。

## 2. 后端：`GET /api/home/portfolio`（JWT 保护）

### 2.1 SQL 聚合口径

聚合全部在 SQL 层完成（`$queryRaw`，WHERE 按 `user_id` 过滤，禁止全表明细拉内存）：

```sql
SELECT currency_code,
       SUM(remaining_qty)              AS remaining_qty,
       SUM(remaining_qty * unit_cost)  AS total_cost
FROM cost_lots
WHERE user_id = $1 AND remaining_qty > 0
GROUP BY currency_code
ORDER BY currency_code ASC
```

- 仅 `remaining_qty > 0` 的币种入结果（耗尽 lot 排除），按 `currencyCode` 升序。
- 顶层 `totalRemainingCost` 用**未舍入的 Decimal 累加后**再 `toFixed(4)`，避免逐币种先舍入引入累积误差。
- `avgUnitCost = total_cost ÷ remaining_qty`，`toFixed(10)`（对齐 `CostLot.unitCost` 的 Decimal(20,10)）；
  服务层对 `remaining_qty = 0` 做除零防御（SQL 已过滤，防御极小量精度边界）。
- `baseCurrency` 取 `UserSettings.baseCurrency`，无 settings 记录为 `null`。
- **口径假设（代码注释已写明）**：`CostLot.unitCost` 以用户**当前** baseCurrency 计价；
  本位币历史变更不对存量 lot 重算，跨口径数据为近似值。

### 2.2 DTO 与响应

- DTO 位于 `services/chat/src/home/dto/home.dto.ts`，每个 `@ApiProperty` 显式标注 type（项目红线）；
  controller 挂既有 `HomeController`，`PortfolioDto`/`PortfolioByCurrencyDto` 经 `@ApiExtraModels` 注册进 Swagger。
- 响应为既有 `{ success, data, message }` 包装；金额一律字符串固定 4 位小数（`toFixed(4)`）。
- `GET /home/state` 的既有响应与断言**未改动**。
- `HomeModule` 已在 `app.module.ts` 注册（home-state-routing 变更引入，本次复用）。

## 3. 前端数据流：双请求并行 + 降级

`lib/hooks/use-home-state.ts` 在既有 state 查询上新增 portfolio 查询，两个 react-query 并行、互不阻塞：

```
useHomeState()
  ├─ stateQuery     GET /home/state     失败 → isError（整页错误态 + 重试）
  └─ portfolioQuery GET /home/portfolio 失败 → 静默降级（仅成本字段置 null，不进错误态）
                                            │
            state 成功 → deriveDashboard(state, portfolio?) 归一为 HomeDashboardData
```

派生规则（纯函数，均无 IO）：

- `focusPlan`：从 `state.plans` 派生（不发额外请求），候选限定 `status="ACTIVE"`，
  `latestPrepDate` 最早者（ISO 8601 按时刻比较）；无 ACTIVE → `null`。
- `progressPercent`：Decimal 十进制运算（金额为字符串，禁止裸 parseFloat 算钱），
  `allocated ÷ target × 100` 四舍五入取整后钳位 0-100；`target = 0 → 0`。
- `daysUntilPrepDeadline`：`date-fns differenceInCalendarDays`（本地时区日历天）；负数 = 逾期（`isOverdue`）。
- `accountCards[].avgUnitCost`：按 `currencyCode` 从 `portfolio.byCurrency` 映射；无记录 → `null`。
- state 失败 → `dashboard` 为 `null`；portfolio 失败 → 仅 `totalRemainingCost`/`baseCurrency`/`avgUnitCost` 降级 `null`。

## 4. 组件结构（`components/business/home/`）

| 文件 | 职责 |
| --- | --- |
| `home-dashboard.tsx` | 仪表盘（真实数据版，纯展示）：顶栏（当天日期 + 录入买入 + 汇率监控角标）/ 4 统计卡 / 账户卡列表 / 计划提醒横幅 |
| `home-empty-state.tsx` | 空状态引导页（本期不改，兼任新用户引导） |
| `index.ts` | 桶文件 |

展示规则：无账户不出「外汇账户」卡；无焦点计划不出「最晚备汇日」卡与横幅；
`latestRateObservedAt = null` 不显示角标；`totalRemainingCost = null` 显示 "—"（portfolio 失败降级）；
逾期文案「已逾期 X 天」（取绝对值，不显示负数倒计时）；通知铃铛、同步失败横幅、待收利息、安全评分卡全部删除。
金额展示走 `formatDisplayAmount`（去尾零、原样渲染，不做前端精度裁剪）；`baseCurrency = null` 时币种标注退化省略。
`app/(protected)/home/page.tsx` 为分流瘦壳：loading 骨架 / 错误态重试 / 空状态 / 仪表盘四分支。

## 5. 导航与占位页

- `app/(protected)/layout.tsx`：`NAV_ITEMS` 固定 5 项（首页→换汇计划→外汇账户→我的报告→设置）；
  高亮规则不变（`/home` 精确匹配，其余前缀匹配）；底部 mock「个人计划卡片」移除，现为真实用户卡 + 登出。
- 新建 `app/(protected)/reports/page.tsx`、`app/(protected)/settings/page.tsx`：
  标题 + 「功能开发中」，无任何操作；守卫由组内 layout 承担，页面零校验代码。

## 7. 与契约/规格的偏差点

| # | 偏差 | 说明 | 处置 |
