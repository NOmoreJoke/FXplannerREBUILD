# 汇率行情（图表）需求规格说明书（SRS）

> 规格只写「用户/业务能得到什么」，用业务语言。
> 不写 API、命令、状态码、数据库——那些是技术方案的事。
> 铁律：预期必须可判定，禁止"体验良好""响应快"这类虚词。

## 一、引言

### 1.1 编写目的与读者

本文档用于对齐「汇率行情」图表页的业务范围与验收标准，是技术方案与测试设计的输入。读者：项目所有者、前后端开发、测试。

### 1.2 项目背景

FXPlanner 已具备多数据源汇率采集（最新价与历史数据）。本次将其可视化：用户在菜单栏进入独立的行情页，以折线图观察币种间的汇率走势，辅助换汇时机判断。

### 1.3 术语与缩写

| 术语 | 含义 |
| --- | --- |
| 本位币 | 用户在引导流程中选定的基准币种，作为图表默认基准 |
| 对比币种 | 叠加在同一张图上与本位币构成汇率曲线的其他币种 |
| 时间档位 | 图表横轴的预设时间范围：7 天 / 30 天 / 90 天 / 1 年 |

## 二、总体描述

### 2.1 系统目标

为登录用户提供菜单可达的汇率走势图：以本位币为基准、支持多币种叠加对比、四个时间档位切换，数据与 AI 助手引用的汇率数据同源一致。

### 2.2 用户角色

| 角色 | 能做什么 |
| --- | --- |
| 未登录用户 | 不可见此模块；直接访问行情页跳转登录页 |
| 登录用户 | 查看任意支持币种相对本位币的走势图，切换时间档位与对比币种 |

### 2.3 边界（明确不做什么）

- 不做 K 线/蜡烛图、技术指标（均线、MACD 等）、涨跌幅标注。
- 不做自选币种收藏、多图布局（一个页面一张主图）。
- 不做分时/实时逐笔粒度（数据粒度以现有历史采集能力为准，由技术方案确认各档位实际数据点密度）。
- 不做自定义任意起止日期（仅四个预设档位）。
- 不做盘后提醒、目标价提醒（已有独立的提醒模块）。
- 不为历史回源能力改造数据源采集层：无回源能力的币对以既有积累数据呈现，不强求补齐。

## 三、功能需求（按模块）

### 模块1：汇率行情页（图表展示）

1. **能力简述**：保护区菜单栏新增「汇率行情」入口，进入后是以本位币为基准的汇率折线图，可叠加对比多币种、切换时间档位。
2. **业务流程**：登录 → 点菜单「汇率行情」→ 看到默认图（本位币 vs 默认对比币种，30 天档）→ 切换时间档位 / 增减对比币种 → 图表实时更新。
3. **核心场景与验收路径**：

   > `登录 → 点菜单「汇率行情」→ 预期：进入行情页，菜单项高亮，默认展示本位币对至少一个币种的折线图与时间档位切换器`
   >
   > `默认进入页面 → 预期：基准为本位币，默认档位为 30 天，图上有坐标轴与图例`
   >
   > `点「1年」档位 → 预期：曲线更新为近一年数据，图例与轴刻度同步变化，无残留旧曲线`
   >
   > `添加第二个对比币种 → 预期：图上新增一条曲线，图例同步出现，两条曲线颜色可区分`
   >
   > `移除一个对比币种 → 预期：对应曲线与图例消失，其余曲线不受影响`
   >
   > `鼠标悬停曲线上某一天 → 预期：浮层显示该日期与各对比币种当日的汇率数值（保留两位以上小数，与数据源精度一致）`
   >
   > `选择数据源暂无数据的币种 → 预期：该币种处提示暂无数据（或仅展示累积序列并标注起始日期），页面不白屏、不报错弹窗`
   >
   > `未登录状态直接访问行情页 → 预期：跳转登录页并带回跳地址`

4. **权限与状态规则**：页面位于登录保护区，复用现有守卫；行情数据为公共数据，不区分用户；页面加载时默认使用当前用户的本位币。

## 四、非功能需求

### 4.1 性能

- 图表数据加载：7/30/90 天档 < 3s；1 年档首次加载 < 15s（仅限具备历史回源能力的币对），之后命中缓存 < 1s；无回源能力的币对展示服务上线日起的累积序列并标注数据起始日期；切换档位或币种后图表更新 < 2s（已有数据时本地立即响应，新数据拉取中显示加载态）

### 4.2 安全

- 仅登录用户可用；无用户私有数据，但页面仍走统一登录守卫。

### 4.3 运行环境

- 与现有 chat-web 一致：现代桌面浏览器（Chrome/Edge/Safari 最新两个大版本）；移动端可用但不做专门优化。
