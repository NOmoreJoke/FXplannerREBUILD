## 4. 资金使用（usage）入口路径（P0-8 验收要求写清）

- 唯一入口：计划详情页头「记录使用」按钮（`/plans/:id`，canModify=ACTIVE 时显示）→ 表单对话框（金额 + 日期 + 备注）。
- 使用后：详情页「使用记录」列表新增行；双进度与 fundStatus 徽标联动（已备齐/已使用完成）。
- 用满 → 「完成确认」按钮 → 二次确认 → 计划 COMPLETED。
- 更正入口：使用记录行「更正」→ `/corrections/new`。
- E2E 覆盖：`e2e/modules/11-plan-usage.spec.ts`（4 用例全绿）。
