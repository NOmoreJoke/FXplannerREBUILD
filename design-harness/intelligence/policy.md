## Never do
1. **严禁未经用户亲手点击就改动账本**，严禁使用倒计时、闪烁红点或自动确认催促用户。
2. **严禁在账本更新后静默覆盖预演单数字**：有实质差异时必须同时展示旧值（删除线）与新值（琥珀底标出），并要求勾选「我已核对最新数字」后才可确认。
3. **严禁使用旋转大公章戳或企业 OA 审批黑话**：个人默认态（`memberCount === 1`）绝不出现「组织审计」「操作员角色」「总控派单给专员」；状态提示一律采用圆润轻巧的存折状态回执签（Receipt Pill）。
4. **严禁仅凭颜色区分事实与预演**：必须同时具备线型差异（实线左绿边 vs 虚线斜纹）与文字标签。
5. **严禁在业务组件内裸写 hex 色值或直接引用 `mint-* / cream-* / jade-* / lilac-*`**，严禁将松翠绿 `bg-commit` 用于非写账本按钮。
6. **严禁模型自由生成未经快照槽位绑定的数字**，严禁回看历史消息时按当前最新账本重算旧槽位（必须只读落库冻结值 `resolved_slots`）。
7. **严禁出现涨跌预测、抄底、最佳时机、稳赚、建议现在买入/推迟换汇等投顾择时话术**。
8. **严禁在达到 20 张未处理预演单上限时静默挤掉最旧的草稿**。
9. **严禁在报错、过期、失效或无权限时只写「操作失败」而不交代账本状态**（必须写明「你的账本没有任何变化」）。

## Must pass
- 检视台与关键业务屏完整覆盖 `empty / running / pending / stale / confirmed / expired / invalidated / legacy / limit / error / noperm` 全部状态。
- 桌面端（`1440px`）与移动端（`390px`）双视口实测渲染检查，**横向溢出严格为 0**；移动端写账本操作栏固定于底部（`sticky`）。
- 核对条如实标注实际执行过的校验层（规则校验 vs 语义复核），绝不夸大。
- 已记入账本状态必含记录编号、记入时间、变更记录留存说明与「回到账本看这笔记录」入口。
