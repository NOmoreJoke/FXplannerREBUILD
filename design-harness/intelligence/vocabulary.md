# 人机共享词汇表（Vocabulary）

| 词汇 | 精确产品语义 | 界面视觉与文案规范 |
| :--- | :--- | :--- |
| **知禾（小禾）** | FXPlanner 的换汇陪伴伙伴（后台多子图编排的唯一前台化身） | 松翠浅底衬线 `禾` 字微章；温和第一人称「我」交流 |
| **账本实况 / 已记入账本** | 已正式写入数据库并留存变更记录的真实账本事实 | `bg-surface-fact` + `border-fact` + `border-l-fact`，配 `● 已记好 · #编号` 回执签 |
| **预演备款单** | 知禾调用只读 `preview` 生成、尚未入账的 `AgentProposal` | `border-proposal` 细虚线外框 + `○ 待你确认` 回执签，标注「尚未记入账本」 |
| **↳ 拟用掉 / ↳ 已用掉** | 预演单在批次扣减表内插入的试算行 / 确认后的实际扣减行 | 试算态用 `bg-proposal-hatch` 斜纹虚线行；确认态切换为 `bg-commit-subtle` 浅翠实线行 |
| **存折状态回执签** | 卡片右上角胶囊型状态签（取代旧版 96px 旋转公章戳） | 圆角胶囊 + 实心/空心圆点，安静传达当前单据状态 |
| **先买先用** | FIFO（先进先出）批次成本核算的白话表达 | 旁附 `?` 解释：「先换好的外币优先使用，方便算清真实成本」 |
| **最低估计** | 包含未填手续费批次（`hasUnknownFee=true`）时的成本口径 | `bg-caution` 提醒条说明原因，附「顺手去补填」入口，绝不当作 `0` |
| **核对回执条** | 知禾完成多步核对后收起的一行过程摘要 | 仅过规则层标 `✓ 数字均取自你的账本 · 不含买卖时机诱导` |
