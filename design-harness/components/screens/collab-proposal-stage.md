## 11 态必备要素表

| 状态 | 检视台核心元素 | 知禾对话栏配合反馈 |
| :--- | :--- | :--- |
| `empty` | 账本实况简报卡（「真实余额与进度，非 AI 估算」）+ 3 张温和试算入口卡（单人态零权限术语） | 分寸承诺说明卡 + 场景快捷提问胶囊 |
| `running` | 知禾 3 步核对进度条展开 + 预演单骨架屏（「知禾试算中 · 确认前不会改动账本」） | 知禾第一人称实时进度反馈 |
| `pending` | 收起式核对回执条 + 虚线预演备款单 + 后果先行 3 条 + `确认记入账本 · 金额 币种` | 温和说明批次扣减与最低估计原因 + 微调追问胶囊 |
| `stale` | 琥珀更新提示条 + 删除线旧值 vs 琥珀新值对照 + 必勾「我已核对最新数字」解锁确认 | 说明账本刚有更新并已按最新余额重算 |
| `confirmed` | 实线左绿边表面 + `● 已记好 · #编号` 回执签 + 已记好清单 + `回到账本看这笔记录` | 告知记录编号与后续可在流水中更正 |
| `expired` | 琥珀过期签（参考价超 5 分钟或容器超 24h）+ 明确写明「账本没有任何变化」+ 深墨黑按钮 `按最新牌价重新试算` | 温和解释牌价时效并引导一键刷新 |
| `invalidated` | 中性收起容器 + `○ 已自动收起` 签 + 白话说明不可逆原因（如计划已取消）与「账本零额外变动」+ 原试算只读留档 | 同步说明原计划状态变化 |
| `legacy` | 中性 `历史只读` 签 + 说明升级前记录未绑定入账状态（防重复建计划）+ 深墨黑按钮 `按今天最新余额重新试算` | 标注历史日期并提供重新试算快捷胶囊 |
| `limit` | 顶栏显示 `20 已满` + 承诺不静默删旧稿且账本未变 + 待处理试算单勾选清单（支持批量「收起不记」腾出位置） | 温和提醒攒满 20 张并引导右侧清理 |
| `error` | 暖红提示卡写明失败原因 + **「还没有生成预演单，你的账本没有任何变化」** + `重新试算` / `去常规表单手动记一笔` | 同步安抚并说明账本未变 |
| `noperm` | **仅多人工作台（`memberCount > 1`）触发**：中性说明当前团队角色分工边界 + 「账本没有任何变化」+ 替代可操作入口 | 温和说明团队分工并主动提议权限内可协助事项 |
