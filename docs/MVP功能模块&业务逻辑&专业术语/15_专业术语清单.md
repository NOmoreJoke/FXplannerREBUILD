# 15 专业术语清单

| 名称 | 白话说明 |
|---|---|
| 本位币 | 统一计算成本的货币。比如选人民币后，买入成本和手续费都用人民币表示。 |
| 目标币种 | 计划要准备、或者本次买入的外币。比如用人民币买美元，美元就是目标币种。 |
| 虚拟外汇账户 | 在产品里记录某种外币还剩多少钱。同币种合在一起，不按银行拆分；这里的钱只是记账记录。 |
| 持仓 | 当前还持有的外币。例如账户里有1,000美元，就是持有1,000美元。 |
| 本金 | 真正用于兑换外币的钱，不包含另收的手续费。 |
| 到账金额 | 本次兑换实际收到的外币数量。 |
| 汇率 | 一种货币能换多少另一种货币。本产品按“1目标币＝多少本位币”显示。例如1美元＝7.2元人民币。 |
| 手续费未知 | 还不知道收了多少手续费，可以暂时不填；与确定没有手续费、填写0不同。 |
| 汇率点差 | 不同买卖报价之间的差额；已经体现在成交汇率里的部分不再重复算成手续费。 |
| 初始持仓 | 首次设置时已经持有的外币。按最后确认时采用的汇率计算初始成本，不随行情变化；参与成本，不参与收益比较。 |
| 记账起点 | 首次设置完成的时刻；清空业务记录后，以清空完成时刻重新起算。不能把起点前的买入重复补进来。 |
| 成本批次 | 每次取得外币分别记下金额和成本，方便以后计算用了哪一笔钱。 |
| 先进先出（FIFO） | 同日先用初始持仓的成本，再按买入日期先后计算普通买入的使用成本。 |
| 单位成本 | 这笔外币的总成本除以外币数量。例如买1,000美元花7,200元，单位成本就是7.2元/美元。 |
| 账户剩余成本 | 账户里还没使用的外币，对应原来花了多少钱。 |
| 平均成本 | 剩余外币的总成本除以剩余数量。不是把每笔汇率直接相加求平均；余额为0时不计算。 |
| 使用成本 | 已经用于某个计划的外币，对应当初花了多少钱。 |
| 目标金额 | 这个计划总共要使用多少外币。 |
| 累计已使用 | 这个计划到目前为止实际使用的外币总额。 |
| 还需使用金额 | 目标金额减去累计已使用金额，最低记为0。 |
| 计划剩余分配 | 留给这个计划、还没使用的外币金额。 |
| 未分配余额 | 账户中还没有留给任何计划的钱。 |
| 还需准备金额 | 还需使用金额减去计划剩余分配，最低记为0。 |
| 分配 | 把账户中的一部分钱留给某个计划。账户总余额不变。 |
| 释放分配 | 不再把这笔钱留给原计划，让它回到未分配余额。账户总余额不变。 |
| 关联计划 | 说明某笔换汇记录与哪个计划有关；仅仅关联，不会自动把钱分配过去。 |
| 钱已备齐 | 计划还需要使用钱，但已分配的钱已经足够。 |
| 确认使用 | 记下一笔已经发生的计划用途支出，减少账户余额及计划分配金额。 |
| 计划完成 | 实际使用总额达到目标，并且剩余分配为0后，由用户点击确认完成。 |
| 取消计划 | 解除该计划还没使用的分配，保留此前的买入和使用记录。 |
| 重新开启 | 已完成计划需要提高目标时，用户确认后让计划回到进行中。 |
| 更正 | 把填错的记录改对，先看修改后的结果，再确认保存。原记录和修改原因都会保留。 |
| 补充分配后立即使用 | 原计划的钱不足时，从未分配余额补上不足部分，再用于本次使用更正；金额只扣一次。 |
| 修改记录 | 记录改了什么、原来是多少、现在是多少，以及修改原因和时间。 |
| 提交结果不明 | 暂时不知道是否保存成功，需要先查清结果，不能直接重复记账。 |
| 预计使用日期 | 预计实际花这笔外币的日期。 |
| 最晚准备日期／最晚安全日期 | 到这一天应该把需要的外币准备好。默认从使用日前一天往前数3个工作日。 |
| 准备缓冲 | 提前准备的工作日天数，默认3天；与分几次准备是两回事。 |
| 开始准备日期 | 从哪天开始安排分批准备。 |
| 准备节点 | 某一次建议准备的日期和金额。 |
| 安心／均衡／主动 | 分别倾向于前期多准备、各次差不多、后期多准备。默认均衡。 |
| 准备逾期 | 超过最晚准备日期，钱还没有备齐。 |
| 站内提醒 | 在产品内部显示的提醒消息，可以关闭。关闭后仍可查看计划状态。 |
| 比较基准 | 假设等到最晚安全时间再一次性换汇，用这个结果与计划的实际结果比较。 |
| 多换目标币 | 花同样多的本位币，最后多得到多少目标币。例如同花1,000美元，多换到200元人民币。 |
| PDF报告 | 可下载的单计划报告。以后修改了记录，已下载的文件不会跟着变化；重新下载会得到更新后的结果。 |

## 常用计算

- 买入外币数量＝兑换本金÷汇率。
- 初始持仓成本＝已有外币数量×最后确认时采用的汇率。
- 账户余额＝所有计划剩余分配的合计＋未分配余额。
- 新增分配最多取两个数中的较小值：未分配余额、该计划还需准备金额。
- 修改分配总额时，最多取两个数中的较小值：该计划还需使用金额、未分配余额加该计划原来分配的金额。

例如：账户有600美元，全部留给某计划。即使计划还缺400美元，也没有钱可以继续分配。修改该计划的分配总额时，最多仍是600美元。

## 先进先出的例子

先买1,000美元花7,800港币，再买1,000美元花8,000港币。使用1,200美元时，先算第一笔1,000美元的成本7,800港币，再算第二笔200美元的成本1,600港币，总使用成本为9,400港币。剩下800美元，成本为6,400港币。
