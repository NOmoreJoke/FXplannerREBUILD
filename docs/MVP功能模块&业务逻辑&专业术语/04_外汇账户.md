# 04 外汇账户

## 账户怎样建立

同一用户的同一币种只有一个账户，不按银行拆分，不同用户的数据分开。

首次买入或确认已有外币时，系统自动建立对应币种账户。更正交易币种后，如果缺少对应账户，也会自动建立；已有账户直接使用。余额变为0后，账户仍保留。

例如，在两家银行分别买入1,000美元和2,000美元，录入后都汇总到同一个美元账户，合计3,000美元。

账户余额来自用户录入的有效记录，不是银行实时余额。首次填写已有外币的方式见[初始化与录入](<02_初始化与录入闭环_待确认.md>)。

## 查看余额和成本

| 内容 | 含义 |
|---|---|
| 账户余额 | 当前还持有多少该币种外币 |
| 已分配金额 | 已留给各个计划、尚未使用的金额 |
| 未分配余额 | 账户余额减去所有计划尚未使用的分配金额 |
| 平均单位成本 | 剩余外币的已记录成本，除以剩余数量 |
| 交易详情 | 每笔买入的外币数量、本金、手续费，以及哪些费用还不清楚 |

余额为0时不计算平均单位成本；未知成本或费用不能当作0。初始持仓的成本是录入时的折算金额，不代表过去的实际支出，也不随行情变化。

## 把外币分给计划

- 创建计划时，可以从同币种的未分配余额中分配金额；以后在计划详情调整。
- 账户页只展示各计划分配金额和未分配余额。分配和调整在计划中操作。
- 新分配只能使用未分配余额。正式确认时，系统再次检查金额，防止同一笔资金被多个计划重复使用。
- 分配不改变账户余额和成本，也不是转账、支出或银行冻结。
- 关联交易只是标明该笔交易对应哪个计划，不等于整笔资金已经分给该计划。

例如，账户有10,000美元，给学费计划分配6,000美元后，账户余额仍是10,000美元，未分配余额是4,000美元。另一个计划不能再使用已分配的6,000美元。

取消计划后，尚未使用的分配金额回到未分配余额。原交易、账户余额和成本不因此改变；已经使用的金额不会恢复。调整目标金额等规则见[创建换汇计划](<06_创建换汇计划.md>)。

## 记录实际使用

用户在计划中填写实际使用金额并确认后，系统才扣减账户余额及该计划分配金额。资金准备够了，不会自动扣减。

允许分次使用。例如，给计划分配6,000美元，本次使用4,000美元后，账户余额减少4,000美元，计划仍保留2,000美元待用。

使用记录保留，不删除原买入交易。系统按先买入的资金先计算使用成本，用户不必选择具体哪一笔，也不设置单独的成本批次页面。

录入实际使用只是记账，不会代用户付款或卖出外币。填错后的处理见[资金使用记录更正](<10_资金使用记录更正.md>)。

## 区分“已备齐”和“已使用完成”

**计划还需金额 = 目标总额 − 已实际用于该计划的金额，最低为0。**

计划还需金额大于0时，剩余分配金额达到还需金额，就显示“资金已备齐”；否则仍有准备缺口。账户里的其他余额不自动计入。

例如，目标10,000美元，已分配10,000美元。使用4,000美元后，还需6,000美元，剩余分配也是6,000美元，仍然显示已备齐。如果剩余分配只有4,000美元，则还差2,000美元。

正常情况下，累计使用达到目标总额、剩余分配为0时，显示“资金已使用完成”；之后由用户确认计划完成。目标总额不会被系统直接改写成还需金额。
