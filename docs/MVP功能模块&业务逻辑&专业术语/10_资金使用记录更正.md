# 10 资金使用记录更正

计划内的使用金额或日期填错后，可以更正。例如实际用了400 USD，却录成4,000 USD。原记录保留，更正用于修正记账，不代表银行退款。

## 操作步骤

1. 从使用详情进入更正，填写新金额或日期以及原因，原因必填。
2. 先看修改前后金额、差额、资金来源、账户余额、计划进度和成本变化。
3. 用户明确确认，系统重新检查资金和相关记录。
4. 全部成功后保存，保留原记录、原因和本次修改历史。

取消或返回修改不影响正式数据。提交时如果余额不足或数据已经变化，重新显示结果，让用户再次确认，不能按旧结果直接扣钱。

## 金额改小

同币种、同计划、日期不变时，减少的金额回到账户可分配余额，计划原来的剩余分配不变。

例如目标10,000 USD，一笔已用4,000改为400，且没有其他资金变动：

| 内容 | 修改前 | 修改后 |
|---|---:|---:|
| 目标金额 | 10,000 | 10,000 |
| 已使用金额 | 4,000 | 400 |
| 账户余额 | 6,000 | 9,600 |
| 本计划剩余分配 | 6,000 | 6,000 |
| 账户可分配余额 | 0 | 3,600 |
| 计划还需要使用 | 6,000 | 9,600 |
| 计划资金缺口 | 0 | 3,600 |

进行中的计划显示尚未备齐；即使账户多了3,600，也不会自动分给原计划。用户要计入计划，需要自己调整分配并确认。系统重算相关成本，不生成“已恢复分配”的记录。

## 金额改大

以下处理适用于币种、所属计划和使用日期不变，且该计划允许修改的情况。

增加的部分先用原计划的剩余分配；不足部分可用同币种未分配余额。后者在本次确认中先分配给原计划，再立即用于更正。不能动用其他计划的分配。

例如4,000改为5,000，只需要补1,000：

| 资金情况 | 处理 |
|---|---|
| 原计划剩余分配足够 | 从原计划分配中使用增加部分 |
| 原计划分配600，未分配余额2,000 | 先用原分配600；再分配400给原计划并立即使用 |
| 原计划分配0，未分配余额6,000 | 分配1,000给原计划并立即使用；最终未分配余额5,000 |
| 原分配加未分配余额仍不足 | 不能提交，原数据保留 |

用户在同一次确认中看清各来源和金额，无需退出更正页面另行分配。

### 分配600、未分配2,000的完整过程

| 处理 | 账户余额变化 | 原计划剩余分配变化 | 未分配余额变化 |
|---|---:|---:|---:|
| 补充分配400 | 0 | +400 | −400 |
| 使用原有分配600 | −600 | −600 | 0 |
| 使用刚补的400 | −400 | −400 | 0 |
| 合计 | −1,000 | −600 | −400 |

无其他分配时，账户余额由2,600变为1,600；原计划分配由600变0；未分配余额由2,000变1,600。原使用4,000改为5,000，不能再按总额重复扣一次。

补充分配与使用必须全部成功才保存。失败、取消不留下半条有效记录；重试不能重复分配或扣钱。保留资金来源、分配与使用的对应关系、前后数量、成本、原因、操作人和时间。

补充分配记录使用本次实际操作时间，不倒写成过去的分配；原使用日期保留。

## 日期填错

同币种、原计划和数量不变时，可以修改使用日期。系统检查新日期当时有没有足够资金，并重新计算使用成本、剩余外币成本和涉及的统计期间。

使用日期不能早于当前账本起点；与起点同日时需确认实际发生在起点之后。成本按“先买的先计算使用成本”处理。同一天重算时，先计初始持仓、再计普通买入、最后计使用，同类记录按首次录入顺序。不能用第二天买入的钱覆盖前一天使用。

例如9月3日买入1,000 USD、9月4日使用400；想把使用改为9月2日，当时没有其他资金，就提示缺400并阻止提交。如果当时另有足够资金，继续检查并计算实际影响。

确认前显示原日期、新日期和成本、期间、计划影响。成功后保留原版本和操作时间；只改日期不会新增使用数量，不会自动改买入日期、补初始余额或更换所属计划。

## 已完成计划改小误录金额

原本正常完成的计划，把误录的使用金额调小后，仍保持“已完成”。目标和剩余分配不变，差额回到账户未分配余额；更新实际使用和成本，保留完成记录，不生成重新开启记录。

例如目标和已用均为10,000 USD，账户余额及剩余分配均为0；改小400后，已用为9,600，账户可分配余额为400。页面展示差额，不要求补齐。

主动提高目标并重新开启是另一种操作，见[创建换汇计划](06_创建换汇计划.md)。

## 使用必须属于计划

每笔使用及其更正都需要明确所属计划，不提供日常外币消费或无计划使用记录。不能通过更正修改使用币种、迁移所属计划或删除整笔记录。原计划剩余分配为0，仍可以按前述流程补充分配后更正。

买入外币可以暂时不关联计划，资金保留为未分配余额。取消计划不会删除原使用历史。
