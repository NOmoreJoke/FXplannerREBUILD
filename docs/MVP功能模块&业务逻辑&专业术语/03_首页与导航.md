# 03 首页与导航

| 功能 | 用户可以做什么 |
|---|---|
| 快速录入 | 直接打开手工表单，记录买入外币；可以不关联计划 |
| 新建计划 | 创建换汇计划 |
| 外币账户摘要 | 查看各币种余额和成本，进入对应账户 |
| 计划摘要与提醒 | 分别查看资金准备情况和实际使用情况，进入计划处理提醒 |
| 报告中心 | 从菜单进入报告中心；在详情查看摘要、下载报告 |
| 设置 | 调整可修改的设置、处理账号和数据请求；本位币仅供查看，不能更换 |

提醒不会自动交易，也不会替用户确认买入、使用或计划完成。

首页不提供图片识别、语音录入、历史回放、路径比较、付费、家庭协作或报告分享入口。也不单独设置行情、空账户创建、成本可信度评分或修复页面。
