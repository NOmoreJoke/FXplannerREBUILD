# FXPlanner 中目标与计划的关系

**提问时间：** 2026-09-08

**问题：** 在 FXPlanner 业务逻辑中，"目标"跟"计划"的关系是什么？

---

## 核心要点

- 目标不是独立实体，而是计划的核心属性：创建计划时填写目标币种、目标金额（最终要**使用**的外币总额，非本次买入金额）、预计使用日期
- 目标是所有计算的核心锚点：还需使用金额 = 目标金额 − 累计已使用；还需准备金额 = 还需使用金额 − 计划剩余分配
- 完成判定以目标为准：累计已使用 = 目标金额且剩余分配为 0，由用户确认完成（不自动完成）
- 目标是终点、计划是过程：分配/分批准备/确认使用都是朝目标推进的度量；计划有状态（进行中/已完成/已取消），目标变化驱动状态变化
- 目标修改被严格管控：修改前预览影响；新目标不能低于已使用金额；调低→同步释放超额分配；调高→产生缺口不自动补齐；已完成计划提高目标走"重新开启并修改目标"；保留原目标及修改记录

## 相关概念

- 计划剩余分配、未分配余额（分配体系）
- 分批准备计划（准备总额 = 目标金额 − 已使用 − 剩余分配）
- 计划完成、重新开启（状态流转）
