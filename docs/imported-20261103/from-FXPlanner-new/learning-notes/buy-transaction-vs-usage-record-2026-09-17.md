# 买入交易 vs 记录实际使用（录入与使用的关系）

**提问时间：** 2026-09-17

**问题：** "记录实际使用"是什么意思？现在不是已经有录入了吗？它和买入录入的关系是什么？

---

## 核心要点

- 买入交易（M4）记的是**钱的流入**：花人民币买外币，形成持仓（CostLot）；现有"录入"只覆盖这一半
- 使用记录（M7）记的是**钱的流出**：把外币实际花出去（如交学费），扣账户余额 + 扣计划分配 + FIFO 消耗成本批次
- 两者是同一笔钱生命周期的一进一出：**买入产出 CostLot，使用消耗 CostLot**
- "关联计划"只是标记，不产生扣减；只有使用记录才真正动余额和分配
- 计划进度是两个独立维度：准备进度（买入累计/目标）≠ 使用进度（使用累计/目标）；钱备齐 ≠ 钱花完
- 分次使用（功能 16）：目标不用一次花完，每次记一笔 UsageRecord、只扣本次金额，剩余继续留在计划里
- 没有使用记录的连锁后果：计划永远"进行中"无法完成、余额虚高、成本摘要算不出（功能 15-18/21/22/25 全依赖它）
- MVP 范围：每笔使用必须挂在某个计划下；"不属于任何计划的使用记录"明确超范围

## 关键示例

```
建计划：准备 10 万日元交学费
  ├─ 准备：分 3 次买入（3 笔交易录入）→ 准备进度 100%   ← 现有"录入"
  ├─ 使用：9/20 支付 5 万（1 笔使用记录）→ 使用进度 50% ← 缺失的 M7
  ├─ 使用：9/28 支付 5 万 → 使用进度 100%
  └─ 完成：使用累计 = 目标 → 用户确认完成
```

## 相关概念

- CostLot / FIFO 成本（`packages/money` + schema）
- 计划分配（PlanAllocation）：确认计划时锁定外币额度，使用时扣减
- M7 资金使用模块（当前未开工，见 `changes/mvp-completion/审查报告与开发计划.md`）
