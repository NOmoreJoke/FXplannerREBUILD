# CAD 余额与账户余额的关系

**提问时间：** 2026-09-11

**问题：** CAD 是什么意思？什么是 CAD 余额？它和"我的账户余额"是什么关系？

---

## 核心要点

- CAD = 加元（Canadian Dollar）的 ISO 4217 标准货币代码，非产品专有名词，文档中仅作示例币种。
- FXPlanner 的账户按**币种**建立：同一用户同一币种只有一个虚拟外汇账户，不按银行拆分。
- 不存在一个总的"我的余额"；每个币种账户各有一个余额（USD / CAD / JPY 互不混算），首页并列展示。
- CAD 余额就是加元账户的余额，即当前还持有多少加元。
- 单账户余额构成：账户余额 = 所有计划剩余分配合计 + 未分配余额；分配不改变余额，确认使用才扣减。
- 余额来自用户录入的有效记录，不是银行实时余额。
