# 计划分配是额度预留（earmark），不是转账

**提问时间：** 2026-09-17

**问题：** "扣减账户余额"扣的是哪里的余额？分配是分配到账户还是分配到计划里？是不是把钱转到计划里？

---

## 核心要点

- 余额 = **按币种的外币账户余额**：一用户一币种一账户（`Account` 表 `@@unique([userId, currencyCode])`）
- 分配 = 把账户里的一部分钱**留给**某个计划，**账户总余额不变**（`15_专业术语清单.md:28`）
- 计划不持有资金，没有"计划钱包"；`PlanAllocation` 表只有 amount/usedAmount，没有 balance 字段
- 分配不是转账、不是支出、不是银行冻结（`04_外汇账户.md:30`），零成本、可随时释放
- 分配的目的：**防止两个计划重复使用同一笔钱**（功能 11）；未分配余额 = 还没留给任何计划的钱
- 真正扣钱的时刻是"使用"：余额 −、该计划分配 −、FIFO 消耗成本批次（`15_专业术语清单.md:32` 确认使用）

## 关键示例

```
账户 10,000 美元
  ├─ 分配 6,000 给学费计划 → 余额仍 10,000，未分配 4,000（钱没动）
  ├─ 旅行计划再分配 5,000 → ❌ 拒绝（未分配只剩 4,000）
  ├─ 学费计划实际使用 4,000 → 余额 6,000，计划剩 2,000 待用（这时才动钱）
  └─ 取消计划 → 未使用的分配回到未分配余额，余额仍不变
```

## 为什么不设计成转账

转账会产生"何时转、按什么汇率转、算不算手续费、成本批次怎么切"一堆问题；
earmark 模式下分配零成本，成本核算全部推迟到使用那一刻（FIFO）。
