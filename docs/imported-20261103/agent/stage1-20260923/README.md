# FXplanner 第一阶段 Agent 设计包

版本：stage-a.v1 · 2026-09-23  
交付性质：配置蓝图、完整系统提示词、接口与数据契约、虚构调用样例及设计校验记录。没有运行代码，不是已接入或可直接启动的服务。

## 从哪里开始

1. [第一阶段设计](01_第一阶段设计与入口.md)：范围、角色、执行流程、Chatbot判断与接入方式。
2. [配置蓝图](agent.config.json)：模型部署占位、角色模式、工具权限、失败策略和未来开关。配置采用本包自定义格式，尚无加载器，不声称兼容某个现成 Agent 平台。
3. [接口说明](02_接口与状态约束.md)及[OpenAPI](contracts/openapi.json)：客户端只提交资源引用；服务端读取授权数据。
4. [五个角色提示词](prompts/00_装配说明.md)：主 Agent、数据、策略、报告、质量审计。
5. [验收清单](03_验收与实现交接.md)：实现时必须通过的正例、反例和未完成前提。

## Chatbot 是否必需

不必。第一阶段主入口建议放在计划详情页的“生成规划报告”和报告页的“重新生成报告”。用户先通过现有表单保存目标、分配和偏好，Agent基于它们解释与输出建议。

未来可增加“问问这份报告”侧栏，只读取指定报告快照，回答持仓成本、分批理由、参考比较及数据缺失问题。修改目标、记录交易、调整分配、确认新安排仍通过明确的业务表单处理。对话功能默认关闭，预留契约不等于首发功能。

## 兼容与范围

- 依据现行 MVP 07、04、06、11、12，以及 Agent PRD V0.2 和 2026-09-22 扩展讨论稿。
- [V0.2完整契约](contracts/base-v0.2.schema.json)从原稿机器可读块原样抽取，仅重排JSON格式；保留47个定义。
- 报告撰写提示词沿用原稿 fxplanner.report.system.v0.2 全文。多角色编排、阶段限制与独立语义审计在外层新增。
- [阶段A契约](contracts/stage-a.schema.json)复用V0.2数据定义，新增主路由、数据清单、策略说明、审计输入输出及外层响应。不把新字段塞进拒绝额外字段的旧接口。
- 公开新接口为设计中的 /api/v1/planning-agent/*；不改写现有 /api/v1/ai/parse* 或已有交易报告接口。
- 第一期只启用 PLANNING、PROGRESS；REVIEW、STOP_SUMMARY 的既有定义保留但不由新入口生成。
- 不要求当前本金余额或现金流；不执行换汇；不新增记账、分配或自动重排接口。

examples 内全部是设计虚构样例，包括V0.2历史日期样例，不表示当前行情或真实客户。Schema检查只能验证结构，跨字段金额、日期、引用和审计结论仍需领域检查。
