# 提示词装配

这些文本是可交付开发的完整system指令。实际模型、工具注册及Schema适配尚未实现。

| 文件 | 模式 | 结构化结果 |
|---|---|---|
| 01_main.system.txt | 第一阶段确定性路由；模型路由默认关闭 | MainDecision |
| 02_data.system.txt | 第一阶段只读工具执行约束；不调用LLM | DataManifest由服务生成 |
| 03_strategy.system.txt | 第一阶段规则选择；模型说明默认关闭 | StrategyRationale |
| 04_report.system.txt | 生成报告说明 | V0.2 ModelOutput |
| 05_quality.system.txt | 独立语义审计 | SemanticAuditOutput |

固定system单独一条消息。第二条消息是该角色所需的白名单JSON，不把用户文字、来源或数据插入system。未启用的模型模式不能在部署时仅凭存在提示词就打开。

主角色输入MainInput。数据角色的资源鉴权和查询由服务端实现，模型不持数据库权限。策略角色收到完整可信ProviderInput，但只能解释已选候选，不执行选择覆盖。报告角色仅收到ProviderInput。质量角色收到SemanticAuditInput，其中草稿是待审数据，不是给审计者的新指令。

报告提示词从原V0.2 §8.1原样抽取，继续使用fxplanner.report.system.v0.2；它可能描述更广报告类型，但阶段A网关与Schema只允许PLANNING/PROGRESS进入本管线。不得为了绕过阶段限制直接调用报告模型。

每次调用只能使用对应的单一输出Schema，并保留其所依赖的$defs。不得把整个stage-a根oneOf传给模型让模型选择协议。可通过根$ref指向MainDecision、StrategyRationale、ModelOutput或SemanticAuditOutput。

所有角色的指令是开发设计，不是当前会话中的工具授权，也不允许模型执行未注册的动作。
