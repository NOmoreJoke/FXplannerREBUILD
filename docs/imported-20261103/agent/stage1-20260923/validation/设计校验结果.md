## 样例验算口径

全部样例为虚构数据，历史日期用于固定验算，不代表当前行情、真实客户或实际模型响应。

- 目标 10,000.00 EUR，历史有效使用 0.00 EUR，本计划拟分配 2,000.00 EUR，缺口为 8,000.00 EUR。
- 三批数量合计 8,000.00 EUR；样例采用 USD 的两位小数、逐批 ROUND_HALF_UP，再汇总为 8,880.00 USD。
- 同目标数量的一次性参考本金为 8,960.00 USD；参考差额 80.00 USD，除以该基准本金后为 0.89%。
- 未知渠道费用保持未知；含费总差额不出数。上述差额只是一组虚构曲线情景的比较。

两位小数仅是此 USD/EUR 样例口径，不是所有币种的统一精度规则。日期检查只证明样例顺序和边界，未验证真实工作日日历。
