# FXplanner MVP PRD

更新日期：2026年9月10日。01—15为功能与业务规则，16—18为配套时序、领域模型和状态机；两部分共同组成当前MVP PRD。

| 项目 | 当前规则 |
|---|---|
| 首次配置 | 用户选择地区、本位币；不选择语言或风险偏好；条款确认在登录／注册 |
| 本位币变更 | 预览并确认 → 停止所涉旧进行中计划 → 释放未用分配 → 保存停止报告依据 → 按新本位币新建后继计划 |
| 目标与计划 | 目标可独立创建；同一目标同时最多一个进行中计划，旧计划保留历史；常规调整沿用计划编号迭代版本 |
| 需求承接 | 后继计划只准备目标总额扣除全历史有效使用后的剩余需求；初始分配为0 |
| 历史成本 | 本金、手续费和成本保留来源原币；不随设置重估或折算；多币种分别列示 |
| 交易范围 | 单笔仅 A→B，A≠B；不支持中间币及跨币种交易路径 |
| 报告 | 停止报告含零使用情况；快照保存与业务变更一致，PDF生成可独立重试 |

## 业务建模

[打开业务建模图册](<19_业务建模图册.html>)：离线查看全部图表，支持放大及查看Mermaid图源。

| 内容 | 使用方式 | 约束 |
|---|---|---|
| 业务时序 | 按功能模块查入口、确认、提交、副作用及返回 | 失败分支和报告异步处理与正文规则一致 |
| 领域模型 | 查逻辑域、实体身份、关系基数、关键字段和不变量 | 逻辑模型不指定物理表、微服务或已实现API |
| 状态机 | 查初始状态、事件、守卫、副作用与禁止迁移 | 生命周期、派生状态、不可变事实分开；未决规则不补造迁移 |
| 图源 | Markdown内含Mermaid；建模图源目录提供MMD、SVG和PNG | Word内嵌对应图形，保持相同业务含义 |
