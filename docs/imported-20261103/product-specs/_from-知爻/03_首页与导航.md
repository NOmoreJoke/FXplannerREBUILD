# 03 首页与导航

| 功能 | 用户可以做什么 |
|---|---|
| 快速录入 | 直接打开手工表单，记录买入外币；可以不关联计划 |
| 新建目标／新建计划 | 目标可独立保存；新建计划选择已有目标，同一目标最多一个进行中计划 |
| 外币账户摘要 | 查看各币种余额和成本，进入对应账户 |
| 计划摘要与提醒 | 分别查看资金准备情况和实际使用情况，进入计划处理提醒 |
| 报告中心 | 从菜单进入报告中心；在详情查看摘要、下载报告 |
| 设置 | 查看并修改默认本位币；先查看停旧建新影响，确认后生效；处理语言、账号和数据请求 |

提醒不会自动交易，也不会替用户确认买入、使用或计划完成。

首页不提供图片识别、语音录入、历史回放、路径比较、付费、家庭协作或报告分享入口。也不单独设置行情、空账户创建、成本可信度评分或修复页面。

## 导航与往返一致性

左侧沿用原功能菜单顺序：首页、外汇账户、换汇计划、路径比较、历史模拟、我的报告、设置。路径比较和历史模拟保留置灰，不开放跳转；不增加“目标”一级菜单。目标入口位于首页和换汇计划模块。

| 来源 | 点击 | 到达与返回 |
|---|---|---|
| 首页／换汇计划 | 新建目标 | 保存后显示目标；可立即制定计划或稍后再说 |
| 换汇计划列表 | 行内查看计划 | 打开该计划；返回保持来源、筛选及列表位置，不跳到默认计划 |
| 外币账户交易台账 | 行内操作列“查看详情” | 打开对应单笔记录；“返回账户”回到原币种账户 |
| 设置 | 修改本位币 | 查看影响后确认停旧建新；结果提供新计划和旧报告入口 |
| 历史已停止计划 | 查看成本报告／查看后继计划 | 指向该计划实际报告与后继；返回恢复原历史列表上下文 |

同一业务状态从不同入口进入，按钮名称、操作区位置及可执行条件一致；返回按钮只出现一次。状态不满足操作条件时不提供可点击的无效入口。标题、表单、核对和成功页必须区分首次新增、已有记录更正及计划更新，不以示例币种替代真实币种。

## 待确定

- 首页摘要的视觉密度和各区域细节。
- 首页摘要展示数量和折叠方式；点击目标或计划始终保留实际对象身份。
- 没有数据、加载中或加载失败时的显示方式。
- 报告内容，见[成本摘要与报告](<11_成本摘要与报告_待确认.md>)。
- 是否另设汇总所有操作记录的日志页面；每笔交易自己的修改记录仍保留。

## 界面要求

| 界面 | 字段与内容 | 主要操作与返回 |
|---|---|---|
| 首页 | 账户摘要、目标／计划摘要、提醒；沿用原左侧功能菜单 | 录入换汇、新建目标、新建计划；摘要进入实际对象 |
| 换汇计划 | 目标和当前计划、准备进度与使用进度，历史计划可查看 | 新建目标、新建计划；行内查看计划 |
| 模块内详情 | 当前对象标题；左侧菜单及选中模块保持一致 | 唯一返回按钮位于同一位置，恢复来源筛选、滚动位置及对象 |

原型画布按功能菜单分模块排列，各模块上方分割线最左侧标功能名；特殊状态排在对应模块一侧。分割线属于画布组织，不进入产品界面。页面中不出现“交互断点”、页面编号、评审备注或“可操作原型”等标记。
