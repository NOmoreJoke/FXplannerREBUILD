# 01 首次使用与设置

## 第一次使用

登录／注册页阅读并确认年龄与必要条款 → 邮箱验证码登录 → 首次配置选择地区和本位币 → 填写已有外币 → 设置站内提醒 → 核对并确认 → 进入首页。

年龄和条款的阅读入口及确认控件放在登录／注册界面；首次配置不重复确认同一版本。首次仍由用户选择本位币，不要求选择界面语言和风险偏好。

| 设置内容 | 怎么处理 |
|---|---|
| 地区 | 香港、中国大陆 |
| 语言 | 默认简体中文，首次配置不设置语言选择；保留设置中切换简体中文／英文的能力，切换语言不改变记账币种 |
| 本位币 | 首次由用户选择；之后可在设置中修改。新交易估算、新计划采用最新本位币，历史金额与来源成本币保持原样 |
| 准备节奏 | 首次配置不选择风险偏好，默认均衡；创建或调整计划时保留安心、均衡、主动，不自动改动已有安排 |
| 已有外币 | 先问是否持有外币；有则按币种填写总金额，以最新汇率计算初始成本；没有则跳过 |
| 站内提醒 | 可关闭；关闭后仍显示计划状态，不发送准备或使用提醒 |
| 最后确认 | 各币种初始金额一起记入账户，先放在未分配余额中 |

已有外币的金额计算和入账规则见[初始化与录入](<02_初始化与录入闭环_待确认.md>)。

## 邮箱和验证码

普通邮箱均可使用，包括Gmail，不另设Google登录。登录页提供服务条款、隐私说明和联系入口，发送验证码前即可阅读。

| 项目 | 规则 |
|---|---|
| 验证码 | 6位数字，支持整段粘贴；发出后10分钟内有效，只能成功使用一次 |
| 重新发送 | 两次发送请求至少间隔60秒，包括明确发送失败后的重试；显示剩余秒数 |
| 发送上限 | 同一邮箱在任意连续1小时内最多5次、连续24小时内最多20次；登录及数据操作验证码合计计算 |
| 发送失败 | 明确发送失败时不扣发送次数，保留邮箱，倒计时结束后可重试；结果暂不明确时先显示“正在确认发送结果”。30秒仍查不到结果，显示“发送结果暂不明确”，60秒倒计时结束后可重新获取 |
| 新旧验证码 | 新验证码发出成功后，同一用途的旧码失效，页面提醒只使用最新发送成功的验证码，延迟收到的旧码不能使用；发送失败时旧码仍按原期限有效 |
| 输错限制 | 同一邮箱、同一用途在连续15分钟内输错5次，该用途的验证码全部失效，暂停验证和发送15分钟；刷新或重新发送不清零错误次数 |
| 不同用途 | 登录、导出、删除数据、注销分别验证；登录码不能用于注销，导出码不能用于删除 |
| 验证成功 | 登录验证成功即完成登录；导出、删除和注销只放行当前邮箱的本次操作，10分钟内完成最后确认，逾期重新验证 |
| 换一个邮箱 | 清空当前验证码和倒计时显示；原邮箱的次数限制仍保留；回填原邮箱时恢复其原倒计时，不迁移账号或草稿 |

刷新、换页面或重新登录不重置发送与输错限制；短时间内出现大量发送请求时，系统限制发送并提示稍后重试。已发出但未收到的邮件仍计入次数；结果不明的发送先占一次额度，明确失败后退回。

验证码错误、过期或已使用时，提示“验证码无效或已过期，请重试或重新获取”。达到次数限制时，明确显示下次可尝试的时间。

验证邮箱之前，不提示“此邮箱已注册”或“尚未注册”。验证通过后，才判断去哪个页面。

### 登录后去哪里

| 账号情况 | 进入哪里 |
|---|---|
| 首次使用 | 登录／注册时完成必要确认后，进入地区和本位币选择；不出现语言、风险偏好选择 |
| 设置未完成，草稿未过期 | 登录／注册页检查年龄及当前必要条款，再返回上次填写位置；同版本已确认不重复勾选，提交前重新核对 |
| 草稿已过期 | 提示“上次设置已过期，请重新填写”，不恢复旧金额 |
| 已完成设置 | 首页；若从某个计划页面登录，则返回本人有权查看的该页面 |
| 条款有重要更新 | 先展示更新内容，处理方式见下节 |
| 正在删除数据或注销 | 进入该请求的进度页面，不直接打开可编辑账本 |

登录状态最长保留7天；到期重新验证邮箱。主动退出后立即结束当前登录，返回键和旧页面不能继续显示个人数据；已保存的记录和未过期草稿保留。

## 年龄与条款

- MVP仅供年满18岁的用户使用。这是本产品的使用条件，采用本人勾选确认，不收集出生日期、身份证照片或其他证件。
- 登录／注册界面的“已满18岁”“同意服务条款”“同意按隐私说明处理外币及计划数据”分别确认，默认不勾选。
- 首次登录／注册时，未满18岁或未同意必要条款，不能填写外币金额、创建计划或进入账本。明确选择未满18岁或点击“不同意并退出”时，清除已有首次设置草稿；仅阅读或暂未勾选不自动清除。已完成设置的账号拒绝新版条款，按下方只读规则处理。
- 条款提供简体中文和英文，显示版本及生效日期。系统记录同意的版本和时间；切换语言不会重复要求同意同一版本。
- 首次设置完成后才遇到新版条款时，拒绝新版不会自动删除原记录。用户仍可查看已有记录、导出、删除数据或注销，但不能新增或修改业务记录。
- 不要求AI授权，不将营销订阅与使用产品绑定。验证码和账号处理结果通知不受站内提醒开关影响。

### 条款更新怎么处理

| 更新内容 | 用户需要做什么 |
|---|---|
| 错别字、排版或联系信息调整 | 展示更新通知，不重复勾选 |
| 服务范围、主要责任或数据处理目的、种类、方式变化 | 下次进入业务页面时展示变化摘要与全文，用户重新同意后再新增或修改记录 |
| 用户暂不接受新版 | 可稍后再看；保留原记录，提供导出、删除和注销入口 |

服务条款和隐私说明要写清运营主体、联系方式、收集哪些数据、用途、保存方式及用户如何提出请求。只因用户未接受新用途，不自动扩大原数据的使用范围。

## 设置草稿怎么保存

| 情况 | 处理方式 |
|---|---|
| 可以开始保存 | 登录／注册完成必要确认后，保存地区、用户选择的本位币、已有外币和提醒；语言及默认节奏由系统带入，不增加首次选择步骤 |
| 保存时机 | 离开输入框或点击下一步时保存，页面显示“已保存”及时间；失败时显示“尚未保存”，不让用户误以为已存好 |
| 保存多久 | 从最后一次成功修改起保留30天；仅打开或刷新页面不延长时间 |
| 中途退出或登录过期 | 已保存部分保留；下次验证同一邮箱后继续，未保存内容不承诺恢复 |
| 多个页面同时填写 | 后提交的页面先检查最新内容；发现已被另一个页面修改，提示重新加载，不直接覆盖 |
| 重新开始 | 先提示将清空哪些未提交内容；确认后仅清空首次设置草稿，不影响已入账记录 |
| 首次草稿修改本位币 | 未入账前可改选；重新查询各外币报价，旧预计成本作废，已填金额保留并重新核对。已入账后走下节的本位币变更流程 |
| 草稿到期 | 删除未提交的设置内容，重新填写；不删除已完成设置后的账本记录 |
| 最后提交成功 | 清除首次草稿，不能再通过“重新开始”覆盖已入账记录；后续修改本位币从设置进入 |

继续填写时，旧汇率只作上次填写记录；最终确认前重新查询并显示本次汇率、报价时间和初始成本，用户检查后才入账。查不到有效汇率时保留草稿重试，不用0或手填价代替。

这里的30天只适用于首次设置草稿，不适用于以后创建计划的草稿。

## 修改默认本位币

设置 → 修改本位币 → 查看影响 → 确认更改（有后继计划时显示“确认更改并新建计划”） → 查看实际生成的新计划／旧计划成本报告。

| 步骤 | 界面与业务要求 |
|---|---|
| 选择 | 展示当前与新本位币；不修改任何历史金额、汇率、费用或成本币种 |
| 查看影响 | 列明本次涉及的进行中计划、拟停止原因、释放分配、新计划剩余需求和本位币；已完成、已取消、已停止计划不重复处理 |
| 确认 | 重新检查目标进度、余额和新安排；全部校验通过后，本位币变更、停旧、释放分配、报告依据及后继计划一起保存；重复提交返回原结果 |
| 成功 | 显示“本位币已更新”；提供“查看新计划”“查看成本报告”“返回设置”。报告文件未就绪时显示生成状态，不提前显示可下载 |
| 取消或校验失败 | 原本位币、原计划、分配均保持不变；保留待修改内容，可返回选择或重新核对 |
| 没有进行中计划 | 仅更新后续默认本位币，不制造旧计划或空报告，也不强制创建新目标 |

同一目标同一时间最多一个进行中计划。切换本位币创建独立后继计划，停止的旧计划保留历史；普通调整仍为同一计划的版本更新。新计划仅承接未完成需求，不自动接收释放资金。完整状态、零剩余及目标币等于新本位币的处理见[创建换汇计划](06_创建换汇计划.md)。

本位币变更前已打开的录入、初始持仓补充或更正草稿，提交时必须核对其记录采用的币种；配置版本变化时重新展示交易对与影响，不静默替换金额单位。历史交易按发生时采用的原本金币种与成本币种保存，旧持仓不重估；正常误填更正继续按原记录规则进行。成本按币种分项，见[成本摘要与报告](11_成本摘要与报告_待确认.md)。

## 账号与数据

在设置中的“账号与数据”提供退出登录、导出数据、删除数据和注销账号。没有设备列表或退出其他设备的独立页面。

导出、删除和注销都要先发送该用途的新验证码，再展示影响，最后由用户确认。验证码只用于这次选定的操作和删除范围；改换范围或操作需重新验证。验证与确认之间，相关记录发生变化时，重新展示影响并确认。提交后本次验证失效；重复点击只返回原请求。丢失邮箱使用权时，先联系邮箱服务商恢复；不能改填另一邮箱取走或删除原账号数据。

### 导出数据

1. 提示本次包含哪些数据，验证邮箱后提交请求。
2. 按提交时已经成功保存的数据制作文件；之后新增或修改的内容留到下一次导出。
3. 7个自然日内提供ZIP文件，包含CSV表格和字段说明：账号设置、首次设置草稿、初始外币、买入、账户、计划、分配、使用、更正、条款同意记录及账号数据请求记录；已有报告文件一并附上。未形成的数据注明为空。
4. 金额标明币种，费用未知保留“未知”，日期带时区；各表可通过记录编号互相对应。不导出验证码、登录凭证或其他用户的数据。
5. 文件生成后在账号与数据中下载，24小时后删除临时文件并关闭链接。下载需登录同一账号，不在邮件中直接附带业务数据；过期后可以重新申请。

导出完成前可以取消，取消后不再交付文件，并删除已经生成的临时文件；取消与生成同时发生时，取消成功就不开放下载。导出完成后可直接申请清空或注销，原下载链接随请求提交失效。

没有实际使用记录也可以导出已有数据。这里是个人数据副本，与单计划PDF报告分开，不提供导回系统的旧数据迁移功能。

### 删除数据

用户先选择删除范围：

| 选择 | 删除什么 | 保留什么 |
|---|---|---|
| 清空业务记录，保留账号 | 全部首次设置草稿、虚拟账户、初始外币、买入、计划、分配、使用、更正及系统保存的报告文件 | 登录邮箱、清空前当前默认本位币、地区语言、准备节奏、提醒设置、首次设置完成标记、必要条款同意和本次请求结果 |
| 删除全部个人数据并注销 | 上述业务数据及账号资料 | 仅处理依法必须保留的记录，见后文 |

清空前显示记录数量和提醒：“这是删除全部业务记录，不是取消一个计划；删除后不能恢复。”用户可先导出，也可直接验证并确认，不强制导出。

- 清空请求提交后，停止新增和修改业务记录及计划提醒，7个自然日内完成。
- 请求期间可查看进度；开始清理前可撤回，撤回后恢复原记录和操作。开始清理后不能撤回，也不再打开原账本。
- 只有全部清理完成后才显示空账本。若处理中断，显示处理异常并继续处理，不把残留数据当成正常账本使用，也不提前显示成功。
- 原来已经完成首次设置：清空后保留完成标记及清空前默认本位币，不重新开放首次设置，以清空完成时刻为新的记账起点，以后可从新买入记录开始记账，不补回清空前的记录。
- 原来还没完成首次设置：清空后返回首次设置，本位币仍可重新选择；不把未提交的选择当成已生效设置。
- 这是删除整套业务数据。平时交易更正仍须保留原记录，不能借此删除单笔使用或跳过计划分配检查。

### 注销账号

1. 展示将删除的账号和数据，提醒可以先导出；重新验证邮箱，最后确认注销。
2. 提交后立即停止账本操作和提醒，退出所有现有登录；新的邮箱验证只进入注销进度页面。
3. 提供7个自然日的撤回期，显示准确截止时间。用户需验证邮箱并点击“撤回注销”，仅登录不算撤回。
4. 撤回期结束后账号关闭，原账号不能恢复；30个自然日内完成在线账号资料及业务数据清理，期限从最初提交请求算起。
5. 清理未完成前，同一邮箱不能重新注册。完成后可作为新账号注册，不能恢复原记录。

撤回注销后，恢复原账号及注销前生效的默认本位币。尚未过期的草稿可继续；不补发暂停期间的计划提醒，已经失效的导出链接不恢复。

### 请求进度、冲突和保留记录

- 显示“已提交、处理中、已完成、已撤回、处理异常”，并显示提交时间、截止时间和结果；注销另显示“等待撤回期结束”。
- 一个账号同时只处理一项导出、清空或注销请求。重复点击返回原请求；要改换操作，先撤回仍可撤回的请求。已经开始清理时，不再接收导出或另一项删除请求。
- 提交清空或注销时，已生成的导出链接立即失效，临时导出包一并删除；确认前提示用户先下载需要的文件。
- 导出超期或清理异常时，显示原因、已完成部分和下一步处理，不自动宣布完成，也不要求反复提交同一请求；提供联系支持入口。
- 账号处理结果以站内进度和必要邮件通知告知；邮件只说明请求状态，不附外币金额和交易明细。通知用途不扩展成邮件换汇提醒。
- 在线数据按上述期限清理；隔离备份在请求提交后最多90天内轮换清除，期间不供日常查询或其他用途。备份恢复时必须再次排除已要求删除的数据。
- 若某类记录确有法律要求必须保留，单独说明记录种类、具体依据、用途限制及截止时间，到期删除；其他数据照常清理。不统一写成“全部保留7年”。
- 已经下载到用户设备的CSV、ZIP或PDF由用户自行管理，系统无法远程删除。

## 界面要求

| 界面 | 字段与内容 | 主要操作与返回 |
|---|---|---|
| 登录／注册 | 邮箱、验证码；年龄、服务条款及隐私说明，展示版本 | 获取验证码、登录；同版本已确认不重复勾选 |
| 首次配置 | 地区、本位币；是否已有外币、持仓、站内提醒；无语言或风险偏好选择 | 下一步、上一步；核对后确认保存，进入首页 |
| 设置 | 当前本位币、语言、站内提醒、账号与数据 | 修改本位币；保留当前设置，进入选择页 |
| 修改本位币 | 当前币种、新币种 | 查看影响；取消返回设置，不保存 |
| 确认本位币变更 | 每个旧计划、新本位币、目标剩余需求、释放分配及新安排；无需新建的项明确列示 | 存在后继计划时为“确认更改并新建计划”；全部无需后继时为“确认更改”；返回修改保留选择 |
| 本位币已更新 | 逐项显示旧计划停止结果、新计划、报告生成状态 | 有对应对象时显示查看新计划、查看成本报告；返回设置 |
