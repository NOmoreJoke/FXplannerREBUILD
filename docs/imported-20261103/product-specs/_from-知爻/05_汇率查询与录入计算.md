# 05 汇率查询与录入计算

新交易估算采用当前默认本位币与目标外币，单笔仅A→B，A为该笔明确采用的本金币种、B为买入币种，两者不能相同。只记录一次直接买入，不提供中间币种或分段路径。统一显示“1单位B = 多少A”，用户核对实际成交数据后确认记账；历史记录始终使用其原交易币种。

## 普通买入的两种填法

| 填写内容 | 系统计算 |
|---|---|
| 支出本金、汇率 | 到账外币金额 = 本金 ÷ 汇率 |
| 支出本金、实际到账外币金额 | 汇率 = 本金 ÷ 实际到账外币金额 |

页面需明确当前使用哪种填法。手续费单独填写，不重复从到账数量扣除；费用不清楚时保留未知，不能当作0。

例如，本金72,480元人民币，汇率为1美元=7.2480元，到账10,000美元；另付42元手续费，总成本72,522元。

## 币种与计算状态

| 情况 | 页面行为 | 保存检查 |
|---|---|---|
| 切换买入币B | 本金单位沿用本次A；到账单位、汇率方向、可关联计划一起更新；使旧交易对报价及自动算出的到账值失效 | 重新取得报价或重新核对用户录入的实际成交值后才能进入核对页 |
| 用户手填实际到账或汇率 | 明确当前采用“本金＋汇率”还是“本金＋实际到账”；切币前保留草稿，切币后要求确认新交易对 | 不把旧手填值静默解释为另一个币种；不自动覆盖已经核对的实际成交值 |
| 修改账号默认本位币 | 新打开表单采用最新默认值；已打开草稿提示配置变化并重新核对交易对 | 不对旧记录或旧草稿只换币种标签后提交 |
| 金额与汇率展示 | 本金、手续费、到账、使用、分配及目标金额按实际币种显示；汇率标明A／B | 不硬编码CAD或CNY；计划关联限该笔目标币种与允许状态 |
| 历史补录／更正 | 使用原交易日期、实际本金及费用币种，按原记录成本口径展示影响 | 不能拿最新默认本位币重标历史金额；按[交易更正](09_交易更正与日志.md)检查 |

参考汇率通过公共计价币相除取得，只是报价计算，不生成任何中间成交。当前报价来源、普通买入查询失败时可用的实际成交录入方式，仍按下方待确定项处理。

## 首次填写已有外币

初始成本 = 已有外币金额 × 本次采用的汇率。编辑页每60秒刷新；从来源报价时间起未满5分钟才有效。最后核对页固定本次数字，过期后重新查询并由用户再次核对。

查不到汇率时保留已填内容并允许重试，不能用手填汇率或0替代后记入初始持仓。记入后成本固定，不随后续汇率变化。具体见[初始化与录入](<02_初始化与录入闭环_待确认.md>)。

初始成本只是按录入时汇率折算出的金额，不代表过去实际花费。录入时的实时汇率也不用于替代收益比较所需的“最晚安全时间”的汇率。

## 金额与精度

日元、韩元金额为整数，其余支持币种最多2位小数。用户输入超出位数时提示修改；系统计算金额按对应币种四舍五入。采用的汇率为8位小数，乘除过程使用十进制，乘法保留完整值、除法不先截短，最后只对金额舍入一次。初始成本按本位币精度计算，正数舍入成0时不能入账。完整规则见[初始化与录入](02_初始化与录入闭环_待确认.md)。

## 待确定

- 选择哪家汇率服务，能否提供[支持币种](<13_MVP功能清单.md>)所需的最新和历史汇率。
- 普通买入重新查询的具体触发节奏与时效阈值；旧交易对计算值必须失效并重新核对。
- 普通买入是否显示报价来源和时间、是否允许改为实际成交汇率。
- 普通买入查询失败时，是否允许手填实际汇率或到账金额。
- 刷新报价与手填实际成交数据的具体切换控件，以及历史补录的凭据核对方式。

## 界面要求

| 界面 | 字段与内容 | 主要操作与返回 |
|---|---|---|
| 录入换汇 | 本金币种、买入币种、兑换本金、手续费、日期、汇率或实际到账、关联计划；仅直接 A→B | 核对记录；取消返回来源；单位随实际币种 |
| 核对换汇记录 | 同一交易对、金额、费用及关联计划；只展示本次有效计算结果 | 确认保存；返回修改保留输入 |
| 换汇记录已保存 | 实际记录、到账金额及币种、实际关联计划（如有） | 查看记录；返回来源账户或计划 |
| 补充报价 | 所需直接交易对、报价值、来源与时间 | 使用报价后回原录入或计划上下文；币种变更后旧计算结果失效 |
