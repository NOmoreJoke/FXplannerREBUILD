# 12 收益指标与报告细则

## 比较原则

收益率和成本节省，都与“到了最晚安全时间才一次性换汇”的结果比较。

这里的“最晚安全时间”指计划最晚准备日期对应的比较时间；具体取当天几点的汇率，还需确定。

- 使用最晚安全时间对应的汇率，不使用创建计划当天或今天的汇率。
- 该笔记录采用的本位币是美元、目标币是人民币时，比较花同样的美元多换到了多少人民币；账号之后更换本位币，不改写该笔记录的金额和币种。
- 新估算与新计划使用当前选择的本位币，历史记录及报告成本仍按各来源原币保留；多成本币分别列示，不能直接相加、统一折成旧计划本位币或合成单一平均成本。
- 报告的详细结构和收益计算办法在 MVP 后期补充；已确定的停止报告、零使用摘要及重试规则见[成本摘要与报告](11_成本摘要与报告_待确认.md)。

## 一个简单例子

花 1,000 美元，实际换到了 7,200 元人民币。假如最晚安全时间的汇率是 1 美元换 7 元人民币：

| 比较项 | 结果 |
|---|---|
| 实际换到 | 7,200 元人民币 |
| 等到最晚安全时间再换 | 1,000 × 7 = 7,000 元人民币 |
| 实际多换到 | 200 元人民币 |

这个例子只说明“多换到多少人民币”。收益率怎么计算、哪些交易计入报告，还需确定。

## 初始持仓的处理

初始持仓是按首次设置最后确认时采用的汇率折算，缺少当年真实买入成本，因此不参与收益率、成本节省或多换外币的比较，但仍参与账户和使用成本。

混合使用时，分开显示初始来源与后续买入来源的使用数量、成本；收益比较只考虑后续真实买入来源，不能把初始部分一并算入。全部来自初始持仓时显示“不计算收益比较”，不能显示0%。具体统计范围和百分比算法仍在下表补充。

本位币变更时，旧计划停止、新计划以独立身份接续同一目标剩余需求，普通调整才是版本迭代。各计划报告分别保留；目标汇总按有效记录去重、成本按币种分组，不将旧计划记录迁移给接续计划。FIFO数量顺序不因本位币变更改变，初始来源与后续真实买入来源仍分别核算。

## 计算办法待确定

| 内容 | 需要补充的问题 |
|---|---|
| 统计哪些金额 | 在后续真实买入来源中，只计算计划已经使用的部分，还是也计算尚未使用的部分？ |
| 收益率 | 用什么金额作为计算比例的基础？ |
| 手续费 | 实际交易费用、比较用的换汇费用分别如何计算？ |
| 比较用的汇率 | 选哪个来源、哪个时区、当天什么时间的汇率？ |
| 暂时算不出 | 最晚安全时间还没到，或缺少对应汇率时，显示什么？ |
| 修改计划日期 | 更改日期后，收益比较采用哪个时间的汇率？旧报告快照保留，新报告另存，具体收益算法待定 |
| 小数处理 | 收益率保留几位小数？报告中分摊与合计产生的显示差额如何处理？金额和汇率基础精度见[初始化与录入](02_初始化与录入闭环_待确认.md)。 |
| 报告内容 | 在已确定的停止摘要、成本币分项和报告版本之外，收益页面和 PDF 还需哪些字段、说明及时间？ |

## 现有报告功能

保留报告中心、计划成本摘要、账户成本摘要和单计划 PDF 下载。有有效使用记录的计划，无论进行中、已完成、已取消还是已停止，都可以下载。本位币变更停止旧计划时，即使零使用，也自动生成可下载的停止摘要，使用均价显示“暂无（N/A）”；其他没有有效使用记录的计划不生成使用报告。未知费用不填0，也不把全账户剩余成本计入停止计划。

历史不折算不等于禁止更正误填。更正成功后更新相关摘要并依据更正记录另存报告，原记录始终归原计划；更正失败不改变原结果，已经下载的 PDF 及原报告快照保持原样。报告生成失败可重试同一任务，不重复创建接续计划。详见[11_成本摘要与报告](<11_成本摘要与报告_待确认.md>)。

## 界面要求

| 界面 | 字段与内容 | 主要操作与返回 |
|---|---|---|
| 成本报告 | 沿用实际报告与计划身份；成本按来源原币分项显示，初始来源与后续买入来源分别列示，不合并多成本币金额或均价 | “下载 PDF”对应当前报告；“返回计划”或“返回报告列表”按进入来源显示，返回同一来源 |
| 报告中的收益比较 | 显示已确认的比较基准；初始持仓不参与收益比较，全部来自初始持仓时显示“不计算收益比较”；未决算法不填入虚构收益值 | 查看当前计划报告，不跳转其他计划或自动切换成本币 |
| 已停止计划报告与生成进度 | 零使用显示停止摘要、使用均价“暂无（N/A）”；显示原币成本分项、报告状态和生成时间，原快照保留 | 生成失败时“重试生成”沿用当前任务；返回同源计划或报告列表，具体规则见成本摘要与报告 |
