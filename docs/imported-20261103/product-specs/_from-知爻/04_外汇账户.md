# 04 外汇账户

## 账户怎样建立

同一用户的同一币种只有一个账户，不按银行拆分，不同用户的数据分开。

首次买入或确认已有外币时，系统自动建立对应币种账户。更正交易币种后，如果缺少对应账户，也会自动建立；已有账户直接使用。余额变为0后，账户仍保留。

尚无初始持仓记录时，提供“补充初始持仓”入口，确认后显示“初始持仓已添加”；已有记录时，从初始持仓详情点击“更正初始持仓”，进入“更正初始持仓”，确认后显示“初始持仓已更正”。新增与更正使用不同页面标题、确认动作和成功提示，新增不要求填写更正原因。

例如，在两家银行分别买入1,000美元和2,000美元，录入后都汇总到同一个美元账户，合计3,000美元。

账户余额来自用户录入的有效记录，不是银行实时余额。首次填写已有外币的方式见[初始化与录入](<02_初始化与录入闭环_待确认.md>)。

## 查看余额和成本

| 内容 | 含义 |
|---|---|
| 账户余额 | 当前还持有多少该币种外币 |
| 已分配金额 | 已留给各个计划、尚未使用的金额 |
| 未分配余额 | 账户余额减去所有计划尚未使用的分配金额 |
| 平均单位成本 | 按来源成本币分组，以该组剩余已记录成本除以该组剩余数量 |
| 交易详情 | 每笔买入的外币数量、本金、手续费，以及哪些费用还不清楚 |

余额为0时不计算平均单位成本；未知成本或费用不能当作0。初始持仓的成本是录入时的折算金额，不代表过去的实际支出，也不随行情变化。

本位币变更不改变各币种账户余额，不重估历史买入、初始持仓及其剩余成本。同一外币账户含不同来源成本币时，成本和平均单位成本分组显示，不能把不同成本币直接相加。未来使用旧持仓时，继续按其原来源成本币计算成本，不改成新的本位币。变更后新发生的换汇默认使用当前本位币；历史补录保留实际发生时的本金、手续费币种与来源成本币，不能按录入时间重新标记。补充初始持仓沿用真实记账起点确认的成本币，历史记录更正沿用原记录成本币。

例如同一 USD 账户同时含以 CNY 和 HKD 记录成本的持仓，账户数量仍汇总为 USD；成本分别显示 CNY、HKD，不生成一个未经换算的“总成本”。停止报告规则见[成本摘要与报告](<11_成本摘要与报告_待确认.md>)。

## 交易记录台账与单笔详情

从币种账户进入交易记录台账，列表只展示该账户的记录；每行最右侧设置“操作”列，点击该行“查看详情”打开对应记录。

买入记录进入该笔“换汇记录详情”；初始持仓进入该币种的初始持仓详情。详情显示所选记录的数据，不使用默认记录替代。

“录入换汇”放在台账右上方，作为新增记录入口。台账下方不再设置“查看买入记录”“查看初始持仓”等单笔操作按钮。

“换汇记录详情”内保留“更正记录”入口；已关联计划时，显示实际关联的计划名称，点击进入该计划详情。未关联时显示“未关联”，不显示跳转入口，也不跳转默认计划。

从单笔详情点击“返回账户”，回到进入详情前的来源币种账户；来源币种与所选记录在跳转时保留。

每个详情页只保留一个返回来源的按钮；往返后按钮名称、所在位置及来源账户不变。输入、核对、返回修改各页保留同一记录和已填内容。币种标签、金额单位随所选币种或记录实际成本币显示，不使用固定的 CAD、CNY 示例单位；更正币种也不能把原记录成本币替换成当前账户设置。

## 把外币分给计划

- 创建计划时，可以从同币种的未分配余额中分配金额；以后在计划详情调整。
- 账户页只展示各计划分配金额和未分配余额。分配和调整在计划中操作。
- 新分配只能使用未分配余额。正式确认时，系统再次检查金额，防止同一笔资金被多个计划重复使用。
- 分配不改变账户余额和成本，也不是转账、支出或银行冻结。
- 关联交易只是标明该笔交易对应哪个计划，不等于整笔资金已经分给该计划。

例如，账户有10,000美元，给学费计划分配6,000美元后，账户余额仍是10,000美元，未分配余额是4,000美元。另一个计划不能再使用已分配的6,000美元。

取消计划，或因本位币变更停止计划后，尚未使用的分配金额回到未分配余额。原交易、账户余额和成本不因此改变；已经使用的金额不会恢复。新本位币下的后继计划不自动承接这部分分配，用户另行确认分配；原交易与使用记录仍归属原计划。停止旧计划、创建后继计划及失败回退规则见[创建换汇计划](<06_创建换汇计划.md#本位币变更时停止旧计划并创建后继计划>)。

## 记录实际使用

用户在计划中填写实际使用金额并确认后，系统才扣减账户余额及该计划分配金额。资金准备够了，不会自动扣减。

允许分次使用。例如，给计划分配6,000美元，本次使用4,000美元后，账户余额减少4,000美元，计划仍保留2,000美元待用。

使用记录保留，不删除原买入交易。系统按先买入的资金先计算使用成本，用户不必选择具体哪一笔，也不设置单独的成本批次页面。

录入实际使用只是记账，不会代用户付款或卖出外币。填错后的处理见[资金使用记录更正](<10_资金使用记录更正.md>)。

## 区分“已备齐”和“已使用完成”

**目标还需金额 = 目标总额 − 该目标全部历史计划的累计实际使用金额，最低为0。**

同一目标同时最多一个进行中计划，该计划按目标还需金额继续准备。目标还需金额大于0时，当前计划剩余分配金额达到还需金额，就显示“资金已备齐”；否则仍有准备缺口。账户里的其他余额不自动计入；已停止计划的历史使用只计入累计使用一次，不复制到后继计划。

例如，目标10,000美元，已分配10,000美元。使用4,000美元后，还需6,000美元，剩余分配也是6,000美元，仍然显示已备齐。如果剩余分配只有4,000美元，则还差2,000美元。

正常情况下，该目标全部历史计划的累计使用达到目标总额、当前计划剩余分配为0时，显示“资金已使用完成”；之后由用户确认当前计划完成。目标总额不会被系统直接改写成还需金额。

## 待确定

- 是否记录银行来源。
- 关联交易时是否同时分配金额。
- 超出计划目标的使用如何处理，以及每次使用如何对应到具体买入记录。
- 其他计划结束后的修改权限，见[创建换汇计划](<06_创建换汇计划.md>)和[资金使用记录更正](<10_资金使用记录更正.md>)。

## 界面要求

| 界面 | 字段与内容 | 主要操作与返回 |
|---|---|---|
| 外汇账户 | 币种、账户余额、已分配、可分配余额；零余额账户保留 | “录入换汇”；点击对应账户“查看”进入该币种账户 |
| {币种}账户 | 账户金额、按来源成本币分组的成本；台账含日期、类型、金额、成本、操作列 | 台账右上“录入换汇”；逐行“查看详情”；无初始记录时显示“补充初始持仓”；“返回账户列表” |
| 换汇记录详情 | 当前所选交易、本金及费用的实际币种、关联计划名称或“未关联” | “更正记录”；点击实际关联计划；唯一“返回账户”保留来源币种 |
| 初始持仓详情 | 所选币种、记账起点、初始金额、原报价、原成本币 | “更正初始持仓”；“返回账户” |
| 补充初始持仓 → 核对初始持仓 | 原记账起点的漏填持仓、有效历史报价及成本币；不要求更正原因 | “核对金额”→“确认保存”；“返回修改”保留输入；成功“初始持仓已添加”后“查看账户” |
| 更正初始持仓 → 确认初始持仓更正 | 原记录、更正值、原因、对余额及成本的影响 | “查看影响”→“确认更正”；“返回修改”保留记录对象；成功“初始持仓已更正”后“查看账户” |
