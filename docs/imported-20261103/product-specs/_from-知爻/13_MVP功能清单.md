# 13 MVP功能清单

## 支持范围

- 地区：香港、中国大陆。
- 语言：简体中文、英文，默认简体中文；首次配置不选择语言或风险偏好，计划节奏仍可选择。
- 币种：港币HKD、美元USD、英镑GBP、澳元AUD、加元CAD、人民币CNY、日元JPY、欧元EUR、新加坡元SGD、新西兰元NZD、新台币TWD、瑞士法郎CHF、韩元KRW、泰铢THB、马来西亚林吉特MYR。
- 本位币：首次配置由用户选择，之后支持修改。后续交易估算及新计划采用最新本位币，历史金额与成本保留各来源原币，不重估、不折算。
- 进度和报告按固定规则自动计算，汇率通过查询服务获取。

## 功能

| 序号 | 功能 | 说明 |
|---|---|---|
| 01 | 首页快速录入 | 点击首页入口，直接打开换汇记录表单。 |
| 02 | 记录买入外币 | 手动填写用本位币买入外币的记录，可以填写汇率后自动计算收到的外币。 |
| 03 | 本金和手续费分开填写 | 本金只填用于兑换的钱；手续费另填，并使用本位币。 |
| 04 | 手续费可以暂时不填 | 没有手续费填0；不知道就留空，仍可保存。 |
| 05 | 显示成本说明 | 有手续费未填时，在平均成本和报告中说明费用可能不完整。 |
| 06 | 选择关联计划 | 可关联同目标币种的进行中计划，也可不关联；历史记录保留原计划归属，不随停旧建新迁移。 |
| 07 | 按币种管理账户 | 同一个币种只有一个虚拟账户，不按银行拆分。 |
| 08 | 查看每笔成本 | 在交易详情查看买入数量、本金、手续费和成本。 |
| 09 | 独立目标与计划 | 目标可先独立保存；同一目标同时最多一个进行中计划，已停止计划保留历史。填写总目标金额与日期；系统按默认提前3个工作日计算最晚准备日。可以调整提前天数、修改目标金额，并先查看修改结果。目标不能低于已经使用的金额。 |
| 10 | 使用已有外币 | 创建计划时自行选择分配多少已有外币，也可以先不分配。 |
| 11 | 避免重复分配 | 同一笔钱不能同时分给两个计划；不同部分可以分给不同计划。 |
| 12 | 确认后才分配 | 填写表单或查看结果时不占用资金，最后确认时重新检查余额。 |
| 13 | 在计划中调整分配 | 创建计划和计划详情中管理分配；账户页显示分配结果。 |
| 14 | 取消计划 | 取消后，尚未使用的分配金额回到未分配余额；已经使用的钱和历史记录保留。 |
| 15 | 记录实际使用 | 记录已经发生的计划用途支出，扣减账户余额和该计划的分配金额。 |
| 16 | 分次使用 | 每次只扣本次使用金额，其余金额继续留给计划。 |
| 17 | 分别显示准备和使用情况 | 钱准备好了不等于已经花完，两项进度分开显示。 |
| 18 | 更新还需金额 | 还需使用金额＝目标金额－同目标全部历史及当前计划累计已使用金额，最低为0。还需使用金额大于0，且已分配的钱足够时，显示钱已备齐；全部使用完时显示资金已使用完成。 |
| 19 | 保留历史记录 | 已停止、已取消及已完成计划保留身份、原规划币、交易／使用及报告，不被后继计划覆盖。 |
| 20 | 修改换汇记录 | 可以改错填的金额、目标币种或日期；先显示影响，检查通过后保存，并保留修改记录。 |
| 21 | 修改使用记录 | 可以改使用金额或日期，填写原因后先查看影响。已完成计划调小误录的使用金额后，仍保持已完成。 |
| 22 | 完成或重新开启计划 | 目标累计使用等于目标、剩余分配为0时，由用户确认完成。已完成计划仅在使用仍等于原目标、无其他进行中计划且本位币与当前设置一致时，允许提高目标并重新开启。 |
| 23 | 分批准备外币 | 默认分3次，提供安心、均衡、主动三种安排，默认均衡；可选择开始准备日。时间太短时减少次数，修改安排需用户确认。 |
| 24 | 站内提醒 | 提醒查看准备安排和实际使用情况；同计划同一天合并提醒；可关闭提醒。 |
| 25 | 成本摘要和报告 | 成本按来源币种分项；本位币变更停止计划时自动出停止报告，零使用也出报告且使用均价不适用；保留原报告，不折算历史。 |
| 26 | 查询汇率并计算金额 | 自动查询最新汇率；输入汇率可算到账金额，也可按实际到账金额算汇率。首次设置已有外币时，用最后确认时采用的汇率计算初始成本。 |
| 27 | 账号和个人数据 | 支持退出、数据导出、清空业务记录和注销；操作前验证邮箱，显示处理进度。清空业务记录不改变本位币。具体见[首次使用与设置](01_首次使用与设置_待确认.md)。 |
| 28 | 补充及更正初始持仓 | 无该币种初始记录时走“补充→核对→确认保存”，不要求更正原因；已有记录按原时点金额和汇率更正，检查余额、分配和历史使用；错币种或漏填需有原时点报价，失败不部分保存。 |
| 29 | 修改计划日期 | 已有计划可以修改日期；哪些状态可以修改、怎样影响原安排，待确定。 |
| 30 | 修改本位币并停旧建新 | 查看影响后确认：停止所涉进行中旧计划、释放未使用分配、保存停止报告依据并创建独立后继计划；新计划只承接目标剩余需求，不自动分配资金。 |
| 31 | 登录注册条款确认 | 年龄、服务条款和隐私确认位于登录／注册，首次配置不重复确认同版本。 |

## MVP暂不提供

- 上传识别、图片识别、语音录入；表单字段仍可正常复制粘贴。
- 单笔交易不支持A→B→C、中间币、跨币种路径优化；不支持卖出外币、以当前记录默认本金币种以外的其他外币作为新交易本金、现金兑换、跨行转账及相关费用。历史记录仍保留发生时采用的原币种。
- 不属于任何计划的使用记录，以及单独撤销整笔使用的操作。
- 每周或每月的准备频率选择、独立的成本批次页面、强制补填未知手续费。
- 历史回放、换汇路径比较、家庭协作、报告分享、账户归档、旧数据迁移。
- 付费积分、订阅、兑换码及其他收费功能。
- Google专用登录、繁体中文、因本位币设置变更而同步折算历史金额和成本。
- 查看登录设备、退出其他设备、独立行情页、单独创建空账户、成本可信度评分及专用修复页。

登录、18岁使用条件、条款更新、30天首次设置草稿及数据处理期限见[首次使用与设置](01_首次使用与设置_待确认.md)。

初始录入每60秒刷新参考价，报价未满5分钟可用；8位汇率计算。日元、韩元金额为整数，其余最多2位小数。同日先计初始持仓；只补记账起点后的真实记录。详见[初始化与录入](02_初始化与录入闭环_待确认.md)。

- 节假日和工作日如何计算；日期修改和已完成、已取消计划的更多处理规则。
- 普通交易和使用更正失败或结果不明时的进一步处理。
- 汇率服务选择，普通买入的刷新方式、查询失败时是否允许手填。
- 收益率算法及报告内容；初始持仓已从收益比较中排除。

详细规则见[业务逻辑清单](14_业务逻辑清单.md)。
