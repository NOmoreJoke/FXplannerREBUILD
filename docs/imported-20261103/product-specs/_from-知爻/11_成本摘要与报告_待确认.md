# 11 成本摘要与报告

## 报告中心

- 按计划查看报告，可按计划状态、目标币种和成本币种筛选；同一目标下的旧计划与接续计划分别展示。
- 在计划详情中查看成本摘要、下载报告。
- 不把不同币种的金额直接相加。

## 计划成本

- 只显示该计划已经使用的外币对应的成本，按各来源原成本币种分别列示；不能把全账户剩余外币成本归入旧计划。只有单一成本币且资料完整时才显示单一使用均价。
- 同日先计算初始持仓，再计算普通买入；普通买入按买入日期先后计算，同日按首次录入顺序。
- 仅把外币分配给计划，还没有实际使用，不计入已使用成本。
- 尚未使用外币时，使用均价显示“暂无（N/A）”；不能显示0，也不能用账户余额或计划分配计算使用均价。
- 正常完成的计划，后来调小误填的使用金额，仍保留完成状态；显示目标金额、修改后的使用金额和差额，不重新提醒补足。

## 账户成本

- 显示账户剩余外币按来源成本币种拆分的已记录成本；多成本币不相加、不统一折成旧计划本位币，也不合成单一平均成本。单一成本币且资料完整时，才显示每单位外币的平均成本。
- 余额为零时，不显示平均成本。
- 缺少的成本不能按零计算。

## 本位币变更后的停止报告

首次设置的本位币由用户选择，之后可以变更。历史本金、手续费、初始成本及交易成本保留原金额和来源币种；后续记录明确采用新的本位币，新估算与新计划使用新本位币。FIFO按原有数量顺序取用资金，成本按来源币种分项保留，不因本位币变更重新折算历史。

变更本位币时，所涉旧进行中计划停止、释放尚未使用的分配，另以独立计划接续同一目标的剩余需求；一个目标同时只有一个进行中计划。普通计划调整升级版本，本位币变更创建新的计划身份，详见[创建换汇计划](06_创建换汇计划.md)。

| 停止报告内容 | 展示规则 |
|---|---|
| 计划身份与停止原因 | 原计划、本位币、目标、停止时间及接续计划入口；旧计划记录继续归旧计划 |
| 停止时的数量 | 目标金额、累计实际使用、释放的未用分配和剩余需求，依据同一次停旧新建结果保存快照 |
| 已使用成本 | 按FIFO对应来源的成本币分别列金额及未知费用提示，不把全账户剩余成本算给旧计划 |
| 零使用 | 自动生成停止摘要，使用数量为0，使用均价“暂无（N/A）” |
| 多成本币与未知费用 | 新旧来源成本币分别列；不统一折算，不合单一均价，未知费用不能作为0 |
| 后续更正 | 原快照保留，按更正后的有效记录另存报告并标明版本、生成时间与更正入口；不迁移到接续计划 |

跨计划查看同一目标时，外币使用数量按有效记录去重汇总，原版本和更正版本不能重复计入；成本按来源币种分组，旧计划停止快照和接续计划报告不重复累计同笔记录。接续计划只使用明确分配给它的资金，不把旧计划已使用数量或成本再次计为新计划使用。

## 收益与节省

所有收益率和成本节省，都与“到了最晚安全时间才一次性换汇”的结果比较。不能改用创建计划当天、今天或各批买入当天的汇率。

例如本位币是美元、目标币是人民币，就比较花同样的美元，实际多换到了多少人民币。具体计算办法见[12_收益指标与报告细则](<12_收益指标与报告细则_待确认.md>)。

## 下载与更正

- 计划有有效的使用记录，就可以下载该计划的 PDF；进行中、已完成、已取消、已停止的计划都适用。
- 本位币变更停止旧计划时自动生成停止成本报告，零使用时也生成可下载的停止摘要。其他没有有效使用记录的计划，不生成使用报告。
- 更正交易或使用记录成功后，相关成本摘要和新下载的报告随之更新，并显示更新时间和修改记录入口。
- 更正失败时，保持原来的结果。已经下载的 PDF 与原报告快照不会被改动；更正成功后生成的报告另存版本，不因账号本位币变化折算历史。
- 进度、金额计算和报告内容由系统按固定规则处理。

### 报告生成与重试

| 状态 | 展示与处理 |
|---|---|
| 生成中 | 显示原计划及报告状态；报告依据已完成的停旧新建结果和原计划快照生成 |
| 已生成 | 可查看、下载，保留生成时间、计划身份和依据的记录版本 |
| 生成失败 | 显示失败状态与“重试生成”；沿用同一报告任务、相同快照，不重复停止旧计划、释放分配或创建接续计划 |

报告生成失败不撤销已经完成的停旧新建，也不使目标出现两个进行中计划。重试只处理报告；若历史记录之后发生更正，另行生成基于更正记录的新报告，旧任务及旧快照继续保留。

## 成本示例

花费 7,000 元人民币，另付 100 元手续费，买入 1,000 美元：

| 项目 | 金额 |
|---|---|
| 总成本 | 7,100 元人民币 |
| 每美元成本 | 7.10 元人民币 |
| 使用 400 美元的成本 | 2,840 元人民币 |
| 剩余 600 美元的成本 | 4,260 元人民币 |

手续费不知道时，显示：“按已录入金额计算，部分交易费用未明确，实际成本可能有所不同。”

首次设置时录入的已有外币，按最后确认时采用的实时汇率计算初始成本。这个金额是系统记账的起点，不代表当年实际买入的花费。没有有效汇率时不能按零入账，详见[02_初始化与录入闭环](<02_初始化与录入闭环_待确认.md>)。

初始持仓参与账户和使用成本，不计收益率、节省金额或多换外币比较。混合使用时，分开显示初始来源和后续买入来源的数量与成本；全部来自初始持仓时显示“不计算收益比较”，不填0%。更正改变来源时，相关数量和成本分类同步更新。

## 后续补充

报告的具体页面与 PDF 样式在后期补充。历史报告快照保留、报告生成状态和失败重试按前述规则处理；还需确定保存期限、是否支持重命名和归档，分批成本分摊的小数处理，以及收益指标的具体计算办法。

## 界面要求

| 界面 | 字段与内容 | 主要操作与返回 |
|---|---|---|
| 我的报告 | 按实际计划列示报告，保留原计划、接续计划及各自报告身份、状态和生成时间 | “查看报告”打开所选报告，不能以默认计划或最新报告替代 |
| 成本报告 | 显示当前报告所属计划、实际使用数量、按来源币种分列的成本、未知费用提示及依据版本；多成本币不合成单一均价 | “下载 PDF”下载当前报告；从计划进入显示“返回计划”，从报告列表进入显示“返回报告列表”，均返回进入前的同一来源 |
| 已停止计划的成本报告 | 显示停止时间、原因、释放分配、剩余需求及原计划报告快照；零使用显示停止摘要，使用均价“暂无（N/A）” | 查看或下载当前计划的对应报告；更正产生的新报告与原快照区分展示，返回沿用进入来源 |
| 报告生成进度 | 显示当前报告任务对应的计划与“生成中”“已生成”或“生成失败”状态 | 失败显示“重试生成”，重试同一任务；已生成后可查看、下载；返回进入前计划或报告列表，不重复创建计划 |
