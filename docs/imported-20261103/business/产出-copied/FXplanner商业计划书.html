PREAMBLE

前言：项目概述

项目一句话定义

面向中国大陆用户的外币支出管理工具——记账 + 汇率信息助手；不触碰支付清算与投资建议，定位于"规划层"的中立信息服务。

申报承诺段（标准措辞）

FXplanner 跨币种现金流规划与外汇成本优化工具，已上线 app.fxplanner.cn（HTTPS+HSTS，ICP 已于 2026-04-09 备案）。已完成 Sprint 0~13D（截至 2026-04-15 v3.51）、上线 18 项核心能力、257 项自动化测试通过。情景 A 自然增长版主线：2026 累计注册 4,500、2027 ¥8 万营收（付费 563）、2028 ¥26 万营收（付费 1,563），2028 当年净利 +¥7.26 万，三年累计 -¥1.41 万（接近持平），累计现金需求峰值 -¥10.31 万（2027 Q3 末），2029 Q1 累计现金流回正。三年累计投入 ~25-46 万元（孵化器口径，不含股权融资）；三年累计带动数字技术岗位 9-14 人次；拟累计软著+商标 8-10 件。陆凯铭为唯一经营 / 持股主体；UBC 数学本科 + FRM L2 候选人 + AI 训练师三级。

核心问题与解决方案

核心问题：中国大陆居民在留学、跨境工作、跨境自由职业、出境消费等场景下，每年人均存在 ¥2,590-6,335 的可避免外汇成本损失。损失的根本原因不是缺资金，而是缺一个"在花钱之前"做最优决策的工具。

解决方案：FXplanner 提供三件能力——(1) 多源银行汇率与信用卡费率聚合；(2) AI 自然语言交易事件录入与置信度标注；(3) 跨币种现金流建模与提醒引擎。

1.2 技术内容与基础原理

总体架构：前后端分离 + 后端 DDD 六大上下文 + 数据库/缓存分离 + 反向代理 + 容器编排，部署于阿里云华东节点的境内环境，遵循数据本地化要求。

已上线架构数据流：终端用户 → Web 前端（Vue3 + TS + Vite + Tailwind / Pinia / vue-i18n / ECharts）→ 1Panel OpenResty 反向代理（HTTPS+HSTS / Let's Encrypt）→ FastAPI 后端容器（Python 3.11 / JWT + 邮箱 OTP / WebSocket）→ {PostgreSQL 16 + Redis 7} → 外部依赖：GLM 智谱 AI（glm-5-turbo）、k780 汇率聚合（中行 / 建行 / 交行）、银行直连（农行 / 工行 / 招行）、邮件 SMTP。

后端 DDD 六大上下文：identity（认证与用户）、subscription（订阅域）、quota（额度与预算）、exchange_rate（汇率域）、ai_interaction（AI 交互）、notification（实时通知）。
