## 6.1 总体口径与本章定位

### 6.1.1 单人创业的申报口径声明

按 `非市场部分审查与补充计划.md` 〇章决策 4（团队形态：单人创业）与决策 5（创始人薪酬按当地最低工资计算）：

| 维度 | 本章口径（孵化器申报）| 不采用口径（对外融资 BP）|
|---|---|---|
| 团队规模 | 单人创业；陆凯铭为唯一经营 / 持股主体（有限公司口径 100% 持股 / 个体工商户或个人经营口径为唯一经营者，不存在外部权益让渡）| 联创团队 / 期权池 / 投后股权稀释 |
| 创始人薪酬 | 按申报地最低工资 × 12 入账（~3.0 万 / 年）| 按行业中位数（产品经理岗 ~25-40 万 / 年）|
| 招聘节奏 | 营收覆盖人力成本后再招（2027 H2 起兼职 / 外包，2028 视营收扩展）| 融资到账后前置招聘工程 / 增长 / 销售团队 |
| 人员预算口径 | 兼职 / 外包小时制（设计 / 内容 / 客服）| 全职薪酬 + 五险一金 + 期权 |
| 单人能力支撑 | AI 工具（Claude Code / Cursor）+ LLM API 放大产能至传统 3-5 人团队当量 | 工具仅作为辅助；人力覆盖广度由头数决定 |
| 团队叙事重点 | 学历背景 + 跨行业产品经验 + AI Native 能力 + 风控 / 合规职业积累 | 联创互补、过往 exit、知名机构背书 |
| 顾问 / 合作方 | 拟合作方向（留学机构 / 金融合规顾问 / 技术导师）；尚未确定可写"拟" | 已签约顾问名单 + 顾问股权 |

### 6.5.3 招聘节奏控制承诺

**孵化器口径承诺**（与 §6.1.1 / `Step3` §4.5.4 一致）：

1. **2026 全年**：创始人独任，0 兼职 / 外包预算；
2. **2027 H1（Q2 起）**：以单篇 / 单项目方式开展内容运营低预算试点，不形成经常性人力成本；P0 专业服务采购按 IP / 法务节点启动；
3. **2027 H2 起**：仅在以下两条件**任一满足**时扩量启动 P1 兼职 / 外包：
   - (a) 商业化已通过双闸门（微信支付 + ICP 经营许可），且付费墙正式上线满 1 个月；
   - (b) 自营内容 / 客服工单 / 设计需求超过创始人单人响应能力（量化阈值：月活跃订阅 ≥ 200 或月工单 ≥ 100 条）；
4. **2028 H1 起**：仅在 2028 Q1 财务复盘**确认营收覆盖兼职 / 外包成本**后，再启动 P2 岗位（兼职开发 / B2B BD）；
5. **不前置招聘**：严禁在商业化未跑通前预付任何全职岗位的前置成本；任何全职岗位的转正必须经过 6 个月以上的兼职 / 外包合作期作为试用。

**口径意义**：招聘节奏控制是孵化器口径"打平 + 造血"目标的关键执行机制，避免过早扩张消耗孵化资金（详见 `Step3` §4.5.4）。

4. **不构成对外承诺**：上表替代比例为创始人内部评估，**不写入 PPT / 申请表 / 申报承诺段**；用作 §6.6 单人放大叙事的内部论据。

**放大机制的本质**：AI 工具不是"替代人"，而是"**放大单人产能约 3 倍**（详见 §6.3.3 中 ~3.2× 当量估算）"——这与传统外包 / 全职团队的边际成本曲线完全不同。具体表现为：

1. **认知负担下降**：单一创始人通过 AI 工具理解前后端 + AI + 运维 + 产品 + 运营 + 客服全栈知识，无需多角色专精分工；
2. **决策延迟降低**：单人决策无需跨角色协调，从需求到上线的端到端响应时间显著缩短；
3. **沟通成本降低**：单人早期推进减少了团队内同步、交接和排期协调成本；
4. **质量保障内化**：创始人同时承担产品 + 开发 + 测试 + 运营，对产品质量的端到端责任感是分工团队难以复制的优势。

### 6.6.4 单人模式的局限性与缓解措施

| 局限性 | 风险 | 缓解措施 |
