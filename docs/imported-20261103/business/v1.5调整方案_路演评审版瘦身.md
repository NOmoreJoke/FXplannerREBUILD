### 2.4【新 P0 - N4】保守退守版三段退路（不反噬主线）

**问题**：v1 方案 §5.5.6 的"创始人自筹 22-25 万兜底"会被评审追问"原先 8-15 万自筹为什么突然能 22-25 万"——形成主线反噬。

#### §5.5.6 完整重写

```markdown
#### 5.5.6 保守退守版组合压力测试

**前提假设**（三因素同时坏）：
- 活跃订阅率 = 1.0%（低于 §5.7 R1 红线）
- 商业化收费上线推迟 6 个月（2027 Q1 → 2027 Q3）
- 外部资金到位率 = 30%

**保守退守版财务重算**（其他锁定值不变）：

| 项目 | 自然增长版（基准） | 保守退守版（不退路）|
|---|---:|---:|
| 2027 营收 | 8.00 万 | ~0.7 万 |
| 2028 营收 | 26.00 万 | ~6.5 万 |
| 三年累计净额 | -1.41 万 | -23 ~ -26 万 |
| 累计现金需求峰值 | -10.31 万（2027 Q3 末） | -23 ~ -26 万（2028 Q3-Q4） |

**问题**：保守退守版下不做任何调整、仅靠创始人自筹兜底将出现 22-25 万元资金缺口；而 §4.3 创始人自筹基线为 8-15 万元——直接缺口 7-17 万元。

**因此保守退守版采用三段退路（A → B → C），按触发顺序优先消耗"低代价路径"，自筹追加为最后兜底**：

##### 退路 A：削减 P2 / P3 支出，三年累计成本压缩至 20-25 万元

| 削减科目 | 自然增长版三年累计 | 退路 A 削减后 | 削减幅度 |
|---|---:|---:|---:|
| 兼职 / 外包（2027-2028） | 8.0 万 | 0-2 万 | **-75% ~ -100%**（创始人继续单人运转） |
| 市场推广（自营内容外，含 KOL / 应用商店 / B2B 拓展） | 5.0 万 | 1-2 万 | **-60% ~ -80%**（仅留种子内容 + 社群冷启动） |
| 一次性合规支出（IP 申报后续件、合规咨询）| 2.7 万 | 1-1.5 万 | **-45% ~ -60%**（首批 IP 完成；商业化合规推迟）|
| 预备费 | 2.27 万 | 0.8-1.5 万 | **-35% ~ -65%** |
| 半固定成本（云服务向上爬坡）| 10.4 万 | 7-8 万 | **-25%**（暂缓 OSS / 监控等增项） |
| **三年累计成本（退路 A）** | **35.41 万** | **~20-25 万** | **-30% ~ -45%** |

**退路 A 触发条件**：2026 Q4 灰度数据印证活跃订阅率 < 1%。
**退路 A 后净额**：累计净额 ≈ -19 ~ -23 万；**累计现金需求峰值 ≈ -19 ~ -22 万（2028 H2）**。

##### 退路 B：推迟商业化 + 招聘冻结 + 免费灰度 + 单次人工报告

| 调整项 | 动作 |
|---|---|
| 商业化 | 推迟至 2028 Q1 后再评估；2027 全年保持免费灰度 |
| 招聘 | 兼职 / 外包冻结至 2028 Q2 后；2026-2027 维持创始人单人 |
| 收入路径 | 单次人工报告（线下合同模式，§3.5.5 ICP 路径 C / B）+ B2B 试点（席位计费），目标 ≤ 3-5 万元 / 年级别现金流入 |
| 内容 / 运营 | 仅维持每周 1-2 条种子内容 + 社群答疑；停掉所有付费投放与 KOL 试投 |

**退路 B 叠加退路 A 后**：
- 三年累计成本 **≈ 17-20 万元**（再削 ~3-5 万）；
- 三年累计净额 **≈ -14 ~ -18 万元**；
- **累计现金需求峰值 ≈ -14 ~ -18 万元（2028 H2）**——**进入创始人原自筹 8-15 万的可承受边界附近**。

##### 退路 C：创始人追加自筹（最后兜底）

仅在退路 A + B 落实后仍存在缺口时启用：
- **追加自筹规模**：≤ 5-7 万元（以填补退路 A + B 后剩余缺口为限，不主动扩张）；
- **资金能力证明**：创始人个人储蓄账户余额证明（脱敏）+ 家庭可调度资金证明（家长签字声明，仅用于孵化器尽调）+ FRM 持证职业的可重新就业能力评估（理论现金流回退选项，不构成承诺）；
- **触发顺序**：退路 A 先行（产品 / 团队侧削减）→ 退路 B 同步（商业化推迟 + 收入替代路径）→ 退路 C 最后（自筹追加）；**三段顺序不可跳级**。

##### 退路总览：三段叠加效果

| 情景 | 累计现金需求峰值 | 创始人自筹缺口 | 是否需股权融资 |
|---|---:|---:|---|
| 自然增长版基准 | -10.31 万（2027 Q3） | 0-2 万（与自筹基线匹配） | ❌ 不需要 |
| 保守退守版（不退路） | **-23 ~ -26 万** | **缺口 7-17 万** | ❌ 仍不需要（但需自筹追加） |
| 保守退守版 + 退路 A | -19 ~ -22 万 | 缺口 3-13 万 | ❌ 不需要 |
| 保守退守版 + 退路 A + B | **-14 ~ -18 万** | **缺口 0-9 万**（自筹基线 8-15 万的可承受边界附近） | ❌ 不需要 |
| 保守退守版 + 退路 A + B + C | **-14 ~ -18 万** | **缺口 0**（C 兜底 ≤ 5-7 万） | ❌ 不需要 |

##### 关键决策点

- 2026 Q4 灰度复盘 = 退路 A 启动决策点；
- 2027 Q1 末累计注册 + 试用→付费转化率验证 = 退路 B 启动决策点；
- **退路 C 仅作为孵化器尽调环节"我有最后兜底"的证明项，不主动启用**——因为退路 A + B 在数据上已使现金需求峰值回到自筹基线可承受边界。

> **结论**：保守退守版下项目仍可活下来，**靠的是低固定成本结构 + 三段退路按序削减 + 创始人自筹仅作最后兜底**——**不形成"原先 8-15 万自筹突然变 22-25 万"的反噬主线**；且全程不依赖股权融资。
```

```markdown
#### 1.3.5 用户主动确认型数据资产（动态护城河）

合规架构（§1.3.4）是结构性静态护城河；除此之外，FXplanner 在数据层正在累积一类**动态数据资产**：

**壁垒形成机制（措辞软化版）**：

> 用户主动确认后的跨行费率、预算节点、家庭场景标签与费用复盘数据，**可逐步形成执行型银行 App 不易直接获得的中立规划数据资产**——并非"无法复制"的绝对壁垒，而是**结构性不易获取的中立信息层**。

- **冷启动期（2026-2027）**：以创始人时间 + 自营内容 + 社群冷启动获得首批用户的真实录入；
- **复利期（2028 起）**：每条用户主动确认的真实费率录入 → 提升对其他用户的费率比较准确度 → 提升留存与口碑 → 拉高新用户主动录入意愿；
- **结构性原因**：执行型工具（银行 App / 跨境支付）以服务自家通道为目标，缺少"中立比较 + 用户主动确认"的产品逻辑；第三方聚合工具缺少"用户主动确认"环节，无法分辨名义费率 vs 真实费率。

> **关键约束**：所有数据**必须来源于用户主动录入与主动确认**；**FXplanner 不存原始账单 / 流水 / 卡号**；数据库中保留的只是脱敏后的费率事实（币种 + 通道 + 卡组织 + 实测费率），符合 §3.5.6 OCR / 账单导入数据处理原则。
```

#### §1.3.4 末段衔接（v2 改写）

```markdown
**结论**：合规架构是 FXplanner 在三年规划期内保持低成本结构 + 高扩张速度的核心制度性能力，而非被动避险措施。**§1.3.5 用户主动确认型数据资产**作为动态层补充，**随用户主动确认录入的累积逐步形成中立规划数据层**——两者共同构成 FXplanner 三年期内的复合壁垒（结构性 + 累积性，非绝对性）。
```

## 六、判断

按本调整方案 v2 落实后：

1. **结构层**：v1.5 路演版正文 25-35 页；评审 5-10 分钟读完；封面后立即出现 §0 评审摘要（已上线事实 + 风险处置 + 12 个月交付物）；尽调包通过申报版 + 支撑材料 S.zip 独立交付。

5. **口径层**：所有锁定值不变；保守退守版三段退路使用"削减 → 推迟 → 自筹"顺序，**不反噬主线 8-15 万自筹基线**；离职状态从"当前在职"修正为"已离职 + S.7 证据"——是事实修正而非口径变更。

**预计总工作量**：1.5-2 个工作日（主源 1 天 + 派生器 0.5 天 + 派生 + 验收 0.5 天）+ 项目方路演前 2 周补完 S.x 证据材料。

**启动条件**：无阻塞，可立即从 Step A0a（园区匹配小节）开始。

- 园区视角（§6.6 + §0.3）从"散落多处"升级为"独立成节"；
