### worktree 并行纪律（必须遵守）

1. **M0 必须先合入 main**：schema、money 包、契约生成产物是所有 worktree 的公共地基，禁止多人抢写
2. **schema 冻结**：W1 起 Prisma schema 只读，需要加字段/索引时停手，回主分支统一改后各 worktree rebase
3. **`app.module.ts` 是已知小冲突点**：各模块注册行由最后合并者统一处理，rebase 时勿强行保留两份
4. **一个 worktree 只做一个模块**：只改 `src/<自己的模块>/` + `test/api/<自己的模块>.spec.ts` + `test/helpers/`（只增不改）
5. **同模块续作（M5.2→correction、M6.2→report）不并行**：上一波完成合入后再开新 worktree 续作
6. **前端页面与所属模块同 worktree 开发**（M1 向导、M3 账户页等），M12 首页整合放 W7 统一做
